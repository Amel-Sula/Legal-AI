# EG/EgyptianLawArticles-HF — Egyptian Civil Code Articles

Egyptian Civil Code articles from the
[TawasulAI/egyptian-law-articles](https://huggingface.co/datasets/TawasulAI/egyptian-law-articles) HuggingFace dataset.

- **Coverage**: 1,105 articles of the Egyptian Civil Code
- **Language**: Arabic (primary) + English translations
- **Data type**: legislation
