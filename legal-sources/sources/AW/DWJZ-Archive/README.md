# AW/DWJZ-Archive — Aruba DWJZ Legislation on Internet Archive

Complete collection of Aruba legislation uploaded by the Directie Wetgeving en Juridische Zaken (DWJZ — Legislation and Legal Affairs Directorate) to the Internet Archive. Covers 5,627 items including:

- **Afkondigingsbladen** (Official Gazette) — individual law publications
- **Landscouranten** (National Gazette) — government announcements
- **Consolidated law texts** — current versions of statutes and codes
- **Ministerial regulations and decrees**

## Data Access

Uses the Internet Archive Advanced Search API to enumerate items, then fetches pre-extracted DjVu OCR text for each document (no PDF processing needed for most items).

- Search API: `https://archive.org/advancedsearch.php?q=creator:"DWJZ - Directie Wetgeving en Juridische Zaken"`
- Text files: `https://archive.org/download/{identifier}/{filename}_djvu.txt`
- Coverage: 1986 to present
