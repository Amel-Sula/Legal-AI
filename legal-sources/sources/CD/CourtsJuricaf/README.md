# CD/CourtsJuricaf — DR Congo Court Decisions (Juricaf)

Democratic Republic of the Congo (Congo démocratique) court decisions fetched from
[Juricaf](https://juricaf.org), the francophone supreme court decisions database
maintained by AHJUCAF.

Covers: Cour de cassation, Cour suprême de justice, and Tribunal de commerce.

## Access

- JSON search API: `https://juricaf.org/recherche/+/facet_pays:Congo_démocratique?format=json`
- Full text per decision: `https://juricaf.org/arret/{id}` (extracted from `div#textArret`)
