# PE/CongresoProyectos

Peru Congress — Bills and Legislative Proposals (SPLEY)

Fetches legislative proposals (proyectos de ley) from the Peru Congress SPLEY
portal. Covers 14,000+ bills from the 2021-2026 parliamentary period with full
text extracted from PDF documents.

- **Source**: https://wb2server.congreso.gob.pe/spley-portal/
- **API**: https://api.congreso.gob.pe/spley-portal-service
- **Data type**: legislation
- **Language**: Spanish
- **Auth**: None required
