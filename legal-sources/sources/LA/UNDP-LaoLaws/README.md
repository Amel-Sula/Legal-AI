# LA/UNDP-LaoLaws

UNDP Official English Translations of 33 major Lao PDR laws.

Translated by UNDP/Singapore/National University of Singapore collaboration.
Covers constitution, business law, criminal law, civil procedure, family law,
property law, tax law, labour law, land law, and more.

**Method:** PDF download from luangprabang-laos.com + text extraction via pdfplumber.

## Usage

```bash
python bootstrap.py test                  # Test connectivity
python bootstrap.py bootstrap --sample    # Fetch 15 sample records
python bootstrap.py bootstrap --full      # Full bootstrap (all 34 PDFs)
```
