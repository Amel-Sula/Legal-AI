# LA/NationalAssembly — Lao National Assembly Legislation Portal

Laws and resolutions from the National Assembly of Lao PDR.

- **Source:** https://na.gov.la/legislation/?lang=en
- **Coverage:** ~216 documents (176 laws, 40 resolutions)
- **Data type:** legislation
- **Format:** PDF (full text extracted via pdfplumber)
- **Access method:** WordPress REST API (`/wp-json/wp/v2/legals`) with ACF repeater fields containing PDF URLs
- **Categories:** governance, defense, economic, culture, foreign affairs
- **Language:** Lao (ພາສາລາວ)
