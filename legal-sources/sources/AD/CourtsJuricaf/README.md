# AD/CourtsJuricaf — Andorra All Courts Decisions (Juricaf)

Andorra court decisions from [Juricaf](https://juricaf.org/), the AHJUCAF francophone court decisions database.

## Coverage

- ~29 decisions
- Full text in French
- Only accessible source for Andorra case law (AD/Courts is blocked due to SPA)
