# SN/ARTP — Senegal Telecom Regulator

Regulatory documents from the Autorité de Régulation des Télécommunications
et des Postes (ARTP), the independent telecom regulator of Senegal.

## Coverage

- **Laws & codes** — Code des Communications Électroniques
- **Reports** — quarterly market monitoring reports
- **Observatory** — tariff observations for mobile, fixed, internet
- **Dashboards** — market indicator dashboards (telephony, internet, postal)
- **Decisions** — regulatory decisions (many are scanned PDFs, skipped if no text)
- **Catalogues** — interconnection catalogues (often scanned, skipped if no text)

Documents are fetched as PDFs from `artp.sn/sites/default/files/documents/`
and full text is extracted via pdfplumber. Scanned/image-only PDFs are skipped.
