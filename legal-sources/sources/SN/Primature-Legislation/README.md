# SN/Primature-Legislation — Senegal PM Office Laws & Regulations

Official laws and regulations from the Senegalese government portal
(primature.sn). Covers codes, decrees, constitution, mining conventions,
and international treaties. Content in French.

## Data access

HTML scraping of Drupal-based site. Each document page has body text and/or
PDF attachments. PDF text is extracted with pdfminer when available.
