# SN/CourSupremeJuricaf — Senegal Cour suprême Decisions (Juricaf)

Senegal court decisions (Cour suprême) from the AHJUCAF francophone court
decisions database via juricaf.org.

## Data

- **Type:** case_law
- **Language:** French
- **Source:** Juricaf / AHJUCAF
- **Access:** JSON API (paginated search) + HTML detail pages with full text
