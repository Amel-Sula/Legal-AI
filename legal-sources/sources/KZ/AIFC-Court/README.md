# KZ/AIFC-Court — Astana International Financial Centre Court

The [AIFC Court](https://court.aifc.kz) is an English-language common law court in Kazakhstan, established as part of the Astana International Financial Centre. It handles international commercial disputes with jurisdiction spanning 41+ nationalities.

~245 English-language judgments and orders since 2019. Unique jurisdiction — a common law island operating within Kazakhstan's civil law system.

## Access

- **Listing**: WordPress REST API at `/wp-json/wp/v2/judgment`
- **Judgments**: Individual pages with embedded PDF links (`a.link_doc`)
- **Format**: PDF judgments with pdfplumber text extraction
- **Auth**: None required
- **Language**: English
