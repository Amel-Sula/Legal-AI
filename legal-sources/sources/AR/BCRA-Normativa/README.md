# AR/BCRA-Normativa

Argentina Central Bank regulatory communications (Comunicaciones "A") from the
Banco Central de la República Argentina (BCRA).

- **Type**: Legislation (banking regulations)
- **Records**: ~8,500 A-type communications
- **Coverage**: 1935–present
- **Language**: Spanish
- **Auth**: None required

## Data Access

Uses the BCRA communications search API (POST endpoint) with `mode=tipo-fecha`
to enumerate all A-type communications. Full text extracted from PDFs hosted at
`bcra.gob.ar/archivos/Pdfs/comytexord/A{number}.pdf`.
