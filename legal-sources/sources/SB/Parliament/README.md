# SB/Parliament — Solomon Islands Parliament Acts

National legislation enacted by the National Parliament of Solomon Islands, from 1981 to present.

## Coverage

- **Type:** Legislation (Acts of Parliament)
- **Period:** 1981–present
- **Language:** English
- **Volume:** ~480 Acts

## Data Source

The official National Parliament website at `parliament.gov.sb` provides Acts organized by year
via a JSON API endpoint (`get_acts.php?year=YYYY`). Each Act is available as a PDF document.

[Open government data](https://parliament.gov.sb/) — official parliamentary legislation of Solomon Islands. No explicit license stated; government legislative documents are public records.
