# CW/PB-Archive — Curaçao Publicatieblad Historical Archive

5,738 historical Curaçao gazette issues (Publicatieblad van Curaçao en onderhoorigheden) from 1861 to 1954, digitized by the Royal Dutch National Library (KB). Covers colonial-era legislation, government decrees, and regulations.

## Data Access

Uses the Internet Archive Advanced Search API to enumerate items, then fetches pre-extracted DjVu OCR text for each issue.

- Search: `title:"Publicatieblad" AND title:"Curaçao"` on archive.org
- Text files: `_djvu.txt` pre-extracted OCR
- Coverage: 1861–1954
