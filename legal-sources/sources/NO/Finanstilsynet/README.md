# NO/Finanstilsynet — Norwegian Financial Supervisory Authority

Finanstilsynet supervises banks, insurance companies, securities firms, auditors, and other financial institutions in Norway. This source collects regulatory doctrine: circulars/guidelines, supervision reports, and formal letters.

## Data Access

- **Sitemap**: XML sitemap at `/sitemap.xml` indexes all pages by category
- **HTML**: Circulars (rundskriv) typically have full inline text
- **PDF**: Supervision reports and letters often link to PDF attachments for full text
- **Categories**: rundskriv (~85), tilsynsrapporter (~1,111), brev (~221)
