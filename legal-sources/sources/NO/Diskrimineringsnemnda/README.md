# NO/Diskrimineringsnemnda — Norwegian Equality and Anti-Discrimination Tribunal

Decisions (vedtak) from Diskrimineringsnemnda, covering discrimination, harassment,
and equality cases since 2006.

- **Source**: https://www.diskrimineringsnemnda.no
- **API**: Umbraco Content Delivery API v2
- **Records**: ~4670 decisions
- **Types**: Vedtak, Uttalelse, Avgjørelse (decisions, opinions, rulings)
- **Language**: Norwegian Bokmål
