# NO/Personvernnemnda — Norwegian Privacy Appeals Board

Appeal decisions from the Norwegian Privacy Appeals Board (Personvernnemnda),
the independent appeals body for Datatilsynet (Data Protection Authority).

- **Coverage:** ~405 decisions from 2001–2025
- **Language:** Norwegian (Bokmål)
- **Update frequency:** Ongoing as new decisions are published
- **Data type:** case_law
- **Access method:** WordPress REST API
