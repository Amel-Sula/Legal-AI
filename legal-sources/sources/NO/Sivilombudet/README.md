# NO/Sivilombudet — Norwegian Parliamentary Ombudsman Statements

Statements (uttalelser) from the Norwegian Parliamentary Ombudsman (Sivilombudet),
covering administrative law complaints and systemic investigations since 2007.
~1,935 statements with full text.

## Data Access

- **API**: WordPress REST API at `/wp-json/wp/v2/uttalelser`
- **Full text**: Available via `content.rendered` field in API response
- **Case numbers**: Extracted from individual statement HTML pages
- **Coverage**: 2007–present, ~1,935 statements
- **Types**: Doctrine (administrative law opinions/statements)
