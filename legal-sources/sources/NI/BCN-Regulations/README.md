# NI/BCN-Regulations — Banco Central de Nicaragua

Regulatory documents from the Banco Central de Nicaragua (BCN): financial laws,
norms, resolutions, and regulations governing banking supervision, monetary
policy, payment systems, and the financial sector.

## Data access

The BCN website HTML pages are behind Radware Bot Manager (hCaptcha), but static
PDF files serve directly without protection. Discovery uses the Wayback CDX API
combined with hardcoded known URLs. ~50 documents total.

## Document categories

- **marco_juridico_financiero/**: Financial laws (Ley Orgánica BCN, Ley General
  de Bancos, Ley de Mercado de Capitales, etc.)
- **normas_disposiciones/**: BCN norms, resolutions, and regulations (encaje
  legal, payment service providers, currency exchange, etc.)
