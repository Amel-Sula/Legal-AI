# ET/NBE-Directives — Ethiopia National Bank Directives

Banking, insurance, forex, microfinance, and payment systems directives from the National Bank of Ethiopia.

- **URL:** https://nbe.gov.et/mandates/directives/
- **Data type:** legislation
- **Records:** ~306 directives
- **Format:** PDF (text extraction via pdfminer)
- **API:** WordPress REST API at `/wp-json/wp/v2/files`

PDF URLs are stored in the `spectra_custom_meta.file_url` field of each
file post. Directives are categorized by taxonomy (banking, insurance,
forex, microfinance, etc.).
