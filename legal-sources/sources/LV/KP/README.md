# LV/KP — Latvia Competition Council (Konkurences padome)

Decisions of the Latvia Competition Council, the state authority
implementing competition policy and supervising compliance with the
Latvian Competition Law.

## Coverage

- **Period**: 2001–present
- **Types**: Mergers, prohibited agreements, abuse of dominance, state aid
- **Language**: Latvian
- **Volume**: ~1,100+ decisions across 112+ pages

## Data Access

Decisions are listed on a paginated table at
`https://lemumi.kp.gov.lv/` and published as individual PDFs at
`https://lemumi.kp.gov.lv/storage/files/...`. The scraper parses
the listing pages and downloads each PDF for full-text extraction
via pdfplumber.
