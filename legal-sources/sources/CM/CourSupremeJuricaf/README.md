# CM/CourSupremeJuricaf — Cameroon Supreme Court Decisions (Juricaf)

Cameroon court decisions (Cour suprême) from the AHJUCAF francophone court
decisions database via juricaf.org.

## Data

- **Type:** case_law
- **Language:** French
- **Source:** Juricaf / AHJUCAF (Association des Hautes Juridictions de Cassation des pays ayant en partage l'usage du français)
- **Access:** JSON API (paginated search) + HTML detail pages with full text
