# CM/SupremeCourt — Cameroon Supreme Court Decisions

Decisions from Cameroon courts via [Juricaf](https://juricaf.org), the AHJUCAF
database of francophone supreme court decisions.

## Coverage

- **~514 decisions** from multiple Cameroon courts
- Supreme Court (Cour suprême): ~189 decisions
- Constitutional Council (Conseil constitutionnel): ~100 decisions
- Courts of Appeal (Cour d'appel): ~86 decisions
- High Courts (Tribunal de grande instance): ~105 decisions
- Other courts: ~34 decisions
- Date range: 1960s–2023
- Languages: French, English (bilingual system)

## Data Access

Uses the Juricaf JSON API (`?format=json`) to list all Cameroon decisions,
then fetches full text from individual decision HTML pages.
