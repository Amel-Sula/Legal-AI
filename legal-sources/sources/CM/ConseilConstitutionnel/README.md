# CM/ConseilConstitutionnel — Constitutional Council of Cameroon (Juricaf)

Cameroon Constitutional Council decisions via [Juricaf](https://juricaf.org),
the francophone court decisions database operated by AHJUCAF.

## Data

- **Type:** case_law
- **Format:** JSON (search API) + HTML (full text from decision pages)
- **Language:** French
- **Volume:** ~100 decisions (2018-2020)
