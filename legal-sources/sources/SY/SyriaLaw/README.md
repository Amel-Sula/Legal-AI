# SY/SyriaLaw — English Syrian Legislation & Case Law

English-language portal covering Syrian legislation and Court of Cassation case law.

## Coverage

- **Legislation**: ~90+ laws across 17 categories (Court System, Civil Code,
  Commercial Law, Company Law, Investment, Property, IP, Finance, Insurance,
  Transport, Employment, Public Procurement, Taxation, Family, Nationality, Criminal)
- **Case Law**: ~280 Court of Cassation judgments organized by legal area
- **Doctrine**: 8 analytical articles on Syrian law topics

## Data access

WordPress REST API at `/wp-json/wp/v2/pages` and `/wp-json/wp/v2/posts`.
Each legislation category is a WP page containing multiple law entries as HTML
tables. Case law is a single large page with ~281 judgment tables.
