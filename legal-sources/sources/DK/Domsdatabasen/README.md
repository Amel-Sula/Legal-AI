# DK/Domsdatabasen — Danish Court Decisions

Danish court decisions from [domsdatabasen.dk](https://domsdatabasen.dk/) via the
[alexandrainst/domsdatabasen](https://huggingface.co/datasets/alexandrainst/domsdatabasen)
HuggingFace dataset.

~3,900 pseudonymized decisions from all Danish courts since January 2022:
- Højesteret (Supreme Court)
- Østre & Vestre Landsret (High Courts)
- Sø- og Handelsretten (Maritime & Commercial Court)
- Byretterne (District Courts)
- Greenlandic courts

Full text extracted from PDFs using EasyOCR and Tika by the Alexandra Institute.
