# DK/Landsskatteretten

Denmark National Tax Tribunal (Landsskatteretten) decisions, published via info.skat.dk.

Covers tax assessment, VAT, customs, and duties decisions. Principled decisions of general interest dating back to 2016.

## Data Source

- **URL**: https://info.skat.dk
- **Type**: case_law
- **Format**: HTML scraping of year listing pages and individual decision pages
- **Auth**: None (open data)
