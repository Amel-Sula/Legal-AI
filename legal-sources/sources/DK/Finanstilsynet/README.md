# DK/Finanstilsynet — Danish Financial Supervisory Authority

Supervisory decisions, sanctions, inspection reports, warnings, and orders
from the Danish Financial Supervisory Authority (Finanstilsynet).

**Source:** https://www.finanstilsynet.dk/tilsyn/inspektion-og-afgoerelser
**Coverage:** 2000–present
**Volume:** ~4,000 decisions
**Language:** Danish

## Data Types

- **doctrine** — supervisory decisions, warnings, orders, inspection reports, sanctions
