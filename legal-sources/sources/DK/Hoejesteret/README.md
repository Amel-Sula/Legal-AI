# DK/Hoejesteret — Danish Supreme Court Decisions

Danish Supreme Court (Højesteret) selected judgments and orders since September 2009.
Approximately 2,850 decisions with full text extracted from official PDF documents.

The data is served by a Tangora CMS platform at `domstol.fe1.tangora.com`.
This is separate from the broader Domsdatabasen (which covers all Danish courts from 2022+).

## Data Access

- Listing with pagination via AJAX (`/listediting.ashx?action=autofetchdata`)
- Individual record pages with metadata and PDF links
- PDFs contain the full judgment text
