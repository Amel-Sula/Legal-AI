# CU/GacetaLegislaciones — Cuba Consolidated Key Laws

Curated collection of ~55 consolidated Cuban laws from the Gaceta Oficial de la
Republica de Cuba's "Algunas Legislaciones Cubanas" section.

Includes the Constitution, Penal Code, Criminal Procedure Code, Family Code,
Labor Code, Foreign Investment Law, and other major legislation.

## Data

- **Source:** https://www.gacetaoficial.gob.cu/es/algunas-legislaciones-cubanas
- **Type:** legislation
- **Format:** PDF gazette publications with full text extraction
- **Language:** Spanish
- **Coverage:** ~55 curated consolidated laws (1961–2024)
