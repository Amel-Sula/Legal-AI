# UZ/ConstitutionalCourt — Uzbekistan Constitutional Court Decisions

Official decisions of the Constitutional Court of the Republic of Uzbekistan
from [konstsud.uz](https://www.konstsud.uz).

Small corpus of ~15 decisions since the court's reconstitution in 2021.
PDFs downloaded and text extracted via pypdf. Uzbek language.

## Data Access

HTML scraping of the decisions page for PDF links, then PDF text extraction.
Some PDFs are scanned images without OCR and are automatically skipped.
