# OM/QanoonLegislation — Oman Royal Decrees and Legislation

Omani legislation from qanoon.om including Royal Decrees, Ministerial Decisions,
and Legal Opinions (Fatwas). ~10,000+ documents in Arabic with full text.

## Data Access

- **API**: WordPress REST API at `/wp-json/wp/v2/posts`
- **Categories**: Royal Decrees (ID 2, ~4,888), Ministerial Decisions (ID 3, ~4,468), Legal Opinions (ID 349, ~687)
- **Full text**: Available via `content.rendered` field in API response
- **Coverage**: Comprehensive Omani legislation corpus
- **Language**: Arabic
