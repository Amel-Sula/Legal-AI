# TM/TaxGov-Legislation

Turkmenistan State Tax Directorate — Normative Legal Acts

PDFs of tax laws, codes, decrees, and regulations from the State Tax
Directorate website (tax.gov.tm). All documents in Turkmen.

## Coverage

- Constitution of Turkmenistan
- Unified Law on Taxes (2022)
- Law on Hydrocarbon Resources
- Budget Code
- Social Protection Code
- Administrative Violations Code
- Laws on Enterprises, SME Support, Business Activities, Ownership, Free Economic Zones
- Tax registration guidelines
- Tax form instructions and amendments
- Regulations on property registration, entrepreneurship, textile products
