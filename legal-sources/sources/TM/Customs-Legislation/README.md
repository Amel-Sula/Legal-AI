# TM/Customs-Legislation — Turkmenistan State Customs Service

Customs legislation published by the State Customs Service of Turkmenistan at [customs.gov.tm](https://customs.gov.tm).

## Coverage

- **Customs Code of Turkmenistan** — full text in English, Russian, and Turkmen (HTML + PDF)
- **Law on Customs Service** — full text in Turkmen and Russian
- **Regulatory Orders** — 6 departmental orders (customs reprocessing, goods destruction, temporary storage, export certification, transport declarations)
- **Customs Schedules** — import/export duty rates, customs fees, excise rates, commodity codes
