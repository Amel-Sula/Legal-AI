# IT/Liguria — Raccolta Normativa Regione Liguria

Regional laws (leggi regionali) of Liguria from the Raccolta Normativa
database of the Assemblea Legislativa della Liguria.

- **Coverage:** 1971 (I Legislature) to present (X Legislature)
- **Data type:** legislation
- **Format:** TXT bulk export per legislature via official download endpoint
- **Source:** https://lrv.regione.liguria.it/liguriass_prod/documenti-tree/leggi/
