# IT/Marche — Legislazione Regionale Marche

Regional laws (leggi regionali) and regulations (regolamenti regionali) of the
Marche Region, sourced from the Consiglio Regionale delle Marche's legislative
database.

- **Coverage:** 1971–present (~2300 acts)
- **Types:** Regional laws (LR), regional regulations (RR), statutory laws (LS)
- **Full text:** Yes — consolidated (vigente) text for active laws; original
  (storico) text for repealed laws
- **Update frequency:** As enacted by the regional legislature

## Data source

Each act is available at a stable URL:
```
https://www.consiglio.marche.it/banche_dati_e_documentazione/leggi/dettaglio.php?arc=vig&idl={N}
```
where `N` is an internal database ID (1–2362+).
