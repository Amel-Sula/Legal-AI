# IT/Umbria — Legislazione Regionale Umbria

Regional laws (leggi regionali) of the Umbria Region, sourced from the Assemblea
Legislativa dell'Umbria legislative database (leggi.crumbria.it).

- **Coverage:** 1971–present (~1400+ laws)
- **Types:** Regional laws (LR)
- **Full text:** Yes — consolidated ("multivigente") text extracted from NIR XML
- **Update frequency:** As enacted by the regional legislature

## Data source

Each law is published as a NIR (Norme in Rete) XML document at a stable URL:
```
http://leggi.crumbria.it/xml/lr{YYYY}-{NN}.xml
```
where `YYYY` is the year and `NN` the sequential law number within the year.
