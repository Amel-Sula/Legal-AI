# SA/ArabicLJP — Saudi Commercial Court Judgments (HuggingFace)

Saudi commercial court judgments from the HuggingFace dataset [mbayan/Arabic-LJP](https://huggingface.co/datasets/mbayan/Arabic-LJP).

- **Records**: 4,290 judgments (3,752 train + 538 test)
- **Language**: Arabic
- **Courts**: Saudi commercial courts
- **Full text**: Yes — `input` field contains case facts, `output` field contains judgment text
- **Source**: Originally sourced from sjp.moj.gov.sa
