# SA/ALARB — Arabic Legal Argument Reasoning Benchmark

Saudi commercial court cases from the HuggingFace dataset [THIQAH-RD/ALARB](https://huggingface.co/datasets/THIQAH-RD/ALARB).

- **Records**: 13,341 cases (12,000 train + 1,341 test)
- **Language**: Arabic
- **Courts**: Saudi commercial courts
- **Full text**: Yes — case_facts, court_reasoning, applicable_laws, verdict
- **Complements**: SA/ArabicLJP (4,290 cases from mbayan/Arabic-LJP, different source/structure)
