# BW/BotswanaLaws — Botswana Consolidated Legislation

**Source:** [BotswanaLaws](https://botswanalaws.com)
**Data type:** Legislation
**Coverage:** ~354 consolidated principal acts

## Description

Centralized access to all current statutory laws of Botswana, including
principal and subsidiary legislation in consolidated format with amendment
annotations. Organized alphabetically with HTML full text.
