# CR/TSE — Costa Rica Tribunal Supremo de Elecciones

Electoral and municipal resolutions from Costa Rica's Supreme Electoral Tribunal (TSE), established in 1949.

- **Electoral resolutions**: 1946–present (~300-500/year in recent years)
- **Municipal resolutions**: 1975–present (~200-300/year in recent years)
- **Format**: ZIP archives of HTML files, organized by year
- **Language**: Spanish
- **Full text**: Yes

## Data Access

Yearly ZIP archives at:
- Electoral: `https://www.tse.go.cr/juris/zip/E-{YEAR}.zip`
- Municipal: `https://www.tse.go.cr/juris/zip/M-{YEAR}.zip`
