# AE/AbuDhabi-Legislation

Abu Dhabi Official Gazette — monthly publication containing laws, decrees, executive council resolutions, circulars and regulations for the Emirate of Abu Dhabi.

- **Coverage:** 2009–2023 (143 English-language gazette editions)
- **Format:** PDF downloads from abudhabi.gov.ae, text extracted via pdfplumber
- **Auth:** None (public downloads)
- **Each record:** One gazette edition with full extracted text
