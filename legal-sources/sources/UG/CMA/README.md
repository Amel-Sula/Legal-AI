# UG/CMA — Uganda Capital Markets Authority

Regulatory notices, market guidelines, enforcement decisions, annual reports, and publications from Uganda's Capital Markets Authority.

## Data types

- **doctrine**: Annual reports, guidelines, regulatory notices, press releases, market communiqués

## Strategy

WordPress REST API at `cmauganda.co.ug/wp-json/wp/v2`:
- **Media API**: 351 attachments — PDFs extracted via pdfplumber
- **Posts API**: 49 posts with inline text (news, press releases, regulatory updates)
- Category mapping for document classification
