# UG/BOU-Regulations — Bank of Uganda Acts, Regulations and Guidelines

Fetches legislation and regulatory documents from the Bank of Uganda's
Strapi CMS API.

## Data sources

JSON API at `https://bou.or.ug/api/supervision` with nested populate queries:
- **Acts** — Financial Institutions Act, Bank of Uganda Act, MDI Act, etc.
- **Regulations** — Capital adequacy, licensing, corporate governance, AML, etc.
- **Supervisory Circulars** — Organized by year, covering policy changes and directives.

PDFs served from `https://bou.or.ug/uploads/`.
