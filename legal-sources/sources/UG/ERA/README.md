# UG/ERA — Uganda Electricity Regulatory Authority

Tariff orders, licensing decisions, regulations, circulars, directives, and
notices published by the Electricity Regulatory Authority of Uganda.

The ERA website (era.go.ug) is WordPress + WP Download Manager. Documents are
discovered via the WordPress sitemap (`wp-sitemap-posts-wpdmpro-1.xml`), then
each package landing page is visited to extract the title and PDF download link.
Text is extracted from PDFs via pdfplumber; scanned/image-only PDFs are skipped.
