# UG/UCC — Uganda Communications Commission

Decisions, rulings, regulations, standards, guidelines, and notices published by
the Uganda Communications Commission (UCC).

The UCC website (ucc.co.ug) is WordPress-based. Documents are fetched via the
WordPress REST API (`/wp-json/wp/v2/media` for PDFs, `/wp-json/wp/v2/posts` for
inline-text content). Text is extracted from PDFs via pdfplumber.
