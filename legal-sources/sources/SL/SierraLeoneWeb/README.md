# SL/SierraLeoneWeb — Sierra Leone Web Laws Archive

**Source:** [sierra-leone.org](https://www.sierra-leone.org/laws.html)
**Type:** legislation
**Records:** ~600+ Acts and Ordinances
**Language:** English

## Overview

The Sierra Leone Web is an independent archive hosting Sierra Leonean legislation as downloadable PDFs. It covers:

- **Post-independence Acts** (1960–2021): ~322 documents including Acts of Parliament, NPRC/AFRC Decrees, the 1991 Constitution
- **Colonial-era Ordinances** (1856–1960): ~291 documents (Caps 1–295)

## Data Access

- **Method:** HTML scraping of index pages + PDF download and text extraction
- **Pages:** `laws.html` (post-independence), `ordinances.html` (colonial era)
- **Auth:** None required
- **Format:** PDF documents
- **URL patterns:** `Laws/YYYY-##.pdf` (acts), `Laws/Cap ##.pdf` (ordinances)
