# CI/DGI-CGI — Code Général des Impôts de la Côte d'Ivoire

Official 2025 edition of the Côte d'Ivoire General Tax Code (Code Général des Impôts),
published by the Direction Générale des Impôts (DGI).

- **Coverage:** ~1,400 articles across 358 HTML pages
- **Content:** Direct taxes, indirect taxes (VAT, excise), registration duties,
  stamp duties, tax procedures (Livre de Procédures Fiscales), and fiscal annexes
- **Language:** French
- **Format:** Structured HTML with article-level granularity
- **Update frequency:** Annual (edition 2025, current as of January 4, 2025)
