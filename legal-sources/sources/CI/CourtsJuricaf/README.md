# CI/CourtsJuricaf — Côte d'Ivoire Courts Decisions (Juricaf)

Ivorian court decisions (Cour suprême and other jurisdictions) from the AHJUCAF
francophone court decisions database via juricaf.org.

## Data

- **Type:** case_law
- **Language:** French
- **Source:** Juricaf / AHJUCAF
- **Access:** JSON API (paginated search) + HTML detail pages with full text
- **Coverage:** ~174 decisions
