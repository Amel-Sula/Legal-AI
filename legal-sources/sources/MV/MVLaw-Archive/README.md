English translations of key Maldivian laws from the Attorney General's old archive site ([old.mvlaw.gov.mv](https://old.mvlaw.gov.mv/ActEng.php)).

- **Language**: English (official translations)

- **Full text**: Yes — PDFs downloaded and text extracted via pdfplumber
