# ZW/ConstitutionalCourt — Zimbabwe Court Decisions (Veritas)

Zimbabwean court decisions published by Veritas Zimbabwe (Firinne Trust) at
[veritaszim.net](https://www.veritaszim.net).

## Coverage

- **High Court**: ~540 judgments (27 pages)
- **Supreme Court**: ~30 judgments
- **Constitutional Court**: ~13 judgments
- **Electoral Court**: ~18 judgments
- **Labour Court**: ~10 judgments
- **Total**: ~610+ judgments

## Data Access

Drupal 7 CMS. Listing pages at `/high-court`, `/taxonomy/term/166` (Supreme),
`/taxonomy/term/102` (Constitutional), `/electoral-court`, `/labour-court`.
Each case node links to a PDF judgment. Full text extracted via PyMuPDF.
