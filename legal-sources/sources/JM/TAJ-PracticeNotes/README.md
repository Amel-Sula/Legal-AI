# JM/TAJ-PracticeNotes

Jamaica Tax Administration — Practice Notes & Bulletins.

## Data

- ~125+ tax practice notes, technical advisories, and bulletins
- Full text extracted from freely accessible PDFs
- Covers GCT, income tax, transfer pricing, withholding tax, FATCA

## Strategy

1. Scrape practice-notes and tax-bulletins pages for PDF links
2. Download PDFs and extract text via pdfminer
3. One record per document
