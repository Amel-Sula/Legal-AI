# BT/Judiciary — Bhutan Judiciary Acts, Rules & Judgments

Fetches legislation (acts and rules) and landmark judgments from the Judiciary of Bhutan website.

## Coverage

- **Acts**: ~130 acts from 1953–2022 (legislation)
- **Rules**: ~17 rules and guidelines (legislation)
- **Judgments**: ~10 landmark Supreme Court decisions (case_law)
- **Languages**: English and Dzongkha (Dzongkha-only documents skipped)
- **Format**: All documents as PDF, text extracted with pdfplumber

## Source

- Acts: https://www.judiciary.gov.bt/posts/first-category/acts
- Rules: https://www.judiciary.gov.bt/posts/first-category/rules
- Judgments: https://www.judiciary.gov.bt/archive-content/judgments
