# RW/OfficialGazette — Rwanda Official Gazette (Igazeti ya Leta)

Rwanda legislation via [RwandaLII](https://rwandalii.org/legislation/), a Laws.Africa platform.
~500 laws including Acts, Ministerial Orders, Presidential Orders, Decrees,
Regulations, and Guidelines. Full text in English extracted from Akoma Ntoso
(AKN) HTML markup.

## Data

- **Type:** legislation
- **Count:** ~500 laws
- **Language:** English
- **Coverage:** Laws, Ministerial Orders, Presidential Orders, Decrees, Regulations, Guidelines
- **Period:** 1959–present (most from 2000s onward)

## Strategy

1. Paginated listing at `/legislation/?page=N` (50 per page, ~10 pages)
2. Each law page contains full AKN HTML; text extracted from `akn-body` div
3. ~6 documents are PDF-only (no inline text) and are skipped
