# GY/EPA-Regulations

Guyana Environmental Protection Agency — Regulations, Guidelines & Policies.

## Coverage

- Environmental regulations (air, water, noise, hazardous wastes, litter, styrofoam, authorisations)
- EIA guidelines (by sector)
- Environmental policies and strategies

~26 regulatory documents. Full text extracted from PDFs via WordPress Download Manager REST API.

## Data access

Uses the WordPress REST API (`/wp-json/wp/v2/wpdmpro`) to enumerate documents, filtered by WPDM category IDs for regulatory content. PDFs are downloaded via the `?wpdmdl=<id>` URL pattern and text is extracted with pdfminer.
