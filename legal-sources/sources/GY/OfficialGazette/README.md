# Official Gazette of Guyana

**Source:** [https://officialgazette.gov.gy](https://officialgazette.gov.gy)
**Country:** GY
**Data types:** legislation
**Status:** Complete

## Description

Official Gazette of Guyana published by the Ministry of Legal Affairs.
Contains bills, notices, legal supplements, regulations, and extraordinary
gazettes. ~2900 issues available as downloadable PDFs.
