# NE/CourDeCassation — Niger Court of Cassation

Niger Court of Cassation (Cour de cassation) decisions via [Juricaf](https://juricaf.org), the AHJUCAF francophone court decisions database.

## Coverage

- **Decisions:** ~275
- **Period:** 2003–present
- **Language:** French
- **Chambers:** Civil, Criminal, Commercial

## Data Source

- **Search API:** `https://juricaf.org/recherche/+/facet_pays:Niger,facet_juridiction:Cour_de_cassation?format=json`
- **Decision pages:** `https://juricaf.org/arret/{id}`
- Full text extracted from `div#textArret` on each decision page
