# NE/CourtsJuricaf — Niger All Courts Decisions (Juricaf)

Niger court decisions from the AHJUCAF francophone court decisions database
via juricaf.org. Covers all Niger courts available on Juricaf:

- Cour suprême (466 decisions)
- Cour de cassation (275 decisions)
- Cour d'appel (56 decisions)
- Tribunal de première instance (12 decisions)
- Cour d'état (4 decisions)
- Cour constitutionnelle (1 decision)

## Data

- **Type:** case_law
- **Language:** French
- **Source:** Juricaf / AHJUCAF (Association des Hautes Juridictions de Cassation des pays ayant en partage l'usage du français)
- **Access:** JSON API (paginated search) + HTML detail pages with full text
- **Note:** Overlaps with NE/CourDeCassation (275 Cour de cassation decisions). DB dedup via ON CONFLICT DO NOTHING.
