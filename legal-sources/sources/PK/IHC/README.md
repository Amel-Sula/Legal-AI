# PK/IHC — Islamabad High Court Judgments

Official judgments from the Islamabad High Court Management Information System (MIS) portal. Provides structured JSON metadata via ASMX web services and full-text PDF judgments.

**URL:** https://mis.ihc.gov.pk/frmSrchOrdr

## Data

- **Type:** case_law
- **Coverage:** 2010–present
- **Records:** Thousands of judgments (2000+ per year)
- **Language:** English
- **Full text:** Extracted from PDF judgments via PyMuPDF
- **Metadata:** Case number, parties, bench, judge, subject, headnotes, citations, applicable statutes
