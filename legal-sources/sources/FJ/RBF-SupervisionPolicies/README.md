# FJ/RBF-SupervisionPolicies

Reserve Bank of Fiji — Supervision Policy Statements

Prudential supervision policies covering banking, insurance, capital markets,
payment services, superannuation, and foreign exchange dealers in Fiji.

## Categories

- **PSPS** — Prudential Supervision Policy Statements (cross-sector)
- **BSPS** — Banking Supervision Policy Statements (~19)
- **ISPS** — Insurance Supervision Policy Statements (~13)
- **CMSPS** — Capital Markets Supervision Policy Statements (~11)
- **SSPS** — Superannuation Supervision Policy Statements
- **RFEDMC SPS** — Foreign Exchange Dealers and Money Changers
- **PSP** — Payment Service Provider policy statements
- **FNPF** — Fiji National Provident Fund

## Data Access

PDF documents are hosted on the RBF WordPress site. The page content is
available via the WordPress REST API (page ID 20542), which returns rendered
HTML containing all PDF download links.
