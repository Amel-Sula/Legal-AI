# FJ/FCCC-Decisions — Fijian Competition & Consumer Commission

Media releases, price control orders, LPG price authorisations, enforcement
decisions, and regulatory determinations published by the FCCC.

- **URL**: https://fccc.gov.fj
- **Records**: ~533 posts (WordPress)
- **Method**: WordPress REST API (`wp-json/wp/v2/posts`) + PDF text extraction
- **Data type**: doctrine
