# YE/Parliament — Yemen House of Representatives Legislative Encyclopedia

Official legislative encyclopedia of the Yemeni House of Representatives (مجلس النواب اليمني), providing laws enacted from 1990 to 2019.

## Data

- **Type**: Legislation
- **Language**: Arabic
- **Coverage**: 1990–2019 (~292 laws)
- **Categories**: 5 legislative periods (1990-1993, 1993-1997, 1997-2003, 2004-2009, 2010-2019)
- **Full text**: Extracted from PDF attachments via PyMuPDF

## Access Method

1. AJAX endpoint (`PWS.asmx/CategoryPosts`) for paginated law listings per category
2. HTML detail pages (`Details?Post={id}`) for metadata and PDF attachment URL
3. PDF download and text extraction
