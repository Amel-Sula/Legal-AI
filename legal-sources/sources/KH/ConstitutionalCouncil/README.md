# KH/ConstitutionalCouncil

Constitutional Council of Cambodia — official constitutional review decisions.

## Source

- **URL**: https://www.ccc.gov.kh/
- **Type**: case_law
- **Coverage**: 2003–2020 (English translations)
- **Records**: ~108 decisions
- **Format**: PDF (born-digital, text-extractable)

## Access

Decisions are listed by year at `decision_en.php?postyear=YYYY`. Each decision
has a detail page (`detail_info_en.php?_txtID=NNN`) with an embedded PDF viewer
and download link. Full text is extracted from the PDFs using PyPDF2.

The site requires browser-like headers (User-Agent) to bypass its WAF.
