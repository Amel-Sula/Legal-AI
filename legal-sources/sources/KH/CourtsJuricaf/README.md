# KH/CourtsJuricaf — Cambodia Court Decisions (Juricaf)

Cambodia (Cambodge) court decisions fetched from [Juricaf](https://juricaf.org),
the francophone supreme court decisions database maintained by AHJUCAF.

Covers: Cour suprême and Conseil constitutionnel.

## Access

- JSON search API: `https://juricaf.org/recherche/+/facet_pays:Cambodge?format=json`
- Full text per decision: `https://juricaf.org/arret/{id}` (extracted from `div#textArret`)
