# KH/CambodiaLawDataset

Cambodia Law Dataset — an open-source collection of Cambodian laws in structured Markdown format, sourced from a public GitHub repository.

## Data

- **Source**: https://github.com/rinn7e/cambodia-law-dataset
- **Format**: Markdown files with full text of laws
- **Languages**: English and Khmer (we fetch English versions)
- **Coverage**: Constitution, Civil Code, Criminal Code, Code of Civil Procedure, Code of Criminal Procedure, and ~60 individual laws
- **Data types**: legislation

## Access

No authentication required. Public GitHub repository accessed via GitHub API.
