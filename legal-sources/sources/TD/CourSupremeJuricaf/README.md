# TD/CourSupremeJuricaf — Chad Supreme Court (Juricaf)

Chad Supreme Court decisions from the AHJUCAF Juricaf database.

**Source URL:** https://juricaf.org/recherche/+/facet_pays:Tchad

## Coverage

- ~451 decisions (1999–2021)
- Cour suprême du Tchad — criminal, civil, and administrative chambers
- Full text in French

## Data Types

- `case_law` — Supreme Court decisions
