# TD/FinancesCodesLois

Chad Ministry of Finance tax codes, customs codes, and finance laws.

## Data

- **Type**: legislation
- **Format**: Joomla CMS HTML pages with PDF downloads
- **Coverage**: Customs Code, tax marking laws, ESSO conventions, debt commission decrees (2016-2018)
- **Volume**: ~21 PDF documents
