# MM/LincolnLegal

Myanmar Laws in English — translations published by Lincoln Legal Services Myanmar.

150+ Myanmar laws translated into English, covering commercial, tax, labor, banking,
IP, consumer protection, and forex/currency control legislation from 1951 to 2026.

**Data**: ~150 laws as PDF downloads from WordPress site.

**Method**: Scrape listing page for PDF links, download each PDF, extract text
via pdfplumber.
