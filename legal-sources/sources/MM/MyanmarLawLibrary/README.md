# MM/MyanmarLawLibrary — Myanmar Law Library

Myanmar laws from [myanmar-law-library.org](http://www.myanmar-law-library.org/). Covers legislation from 2012-2022 across multiple government eras. PDFs in Burmese (Myanmar script) extracted via pypdf.

## Data Coverage

- **Type:** Legislation (Pyidaungsu Hluttaw laws)
- **Period:** 2012-2022
- **Language:** Burmese (Myanmar Unicode)
- **Eras:** NLD (2016-2020), USDP (2012-2016), State Administration Council (2021-2022)
