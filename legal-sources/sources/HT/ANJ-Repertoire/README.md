# HT/ANJ-Repertoire

**Haiti — Assemblée Nationale de la Jeunesse — Répertoire des Lois**

Curated collection of ~40 key Haitian legal documents covering constitutions
(1801–1987), major laws, decrees, codes (penal, customs, labour, aviation),
and foundational historical documents (1804 Act of Independence, letters
from Toussaint Louverture, Dessalines decrees).

- **Source**: https://www.assembleenationaledelajeunesse.com/repertoire-des-lois-de-la-republique-d-haiti
- **Data type**: legislation
- **Language**: French (some Haitian Creole)
- **Auth**: None (public access)
- **Strategy**: HTML scraping — index page lists all documents, each has full text on its own page
