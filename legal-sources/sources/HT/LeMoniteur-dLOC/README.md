# HT/LeMoniteur-dLOC — Haiti Official Gazette

Le Moniteur (journal officiel de la République d'Haïti) digitized by the University of Florida
as part of the Digital Library of the Caribbean (dLOC).

- **Coverage**: 1867 onwards (~3,421 issues)
- **Language**: French
- **Content**: Laws, decrees, presidential orders, administrative decisions
- **Access**: UFDC Patron API (structured JSON, no auth required)
- **Full text**: OCR from digitized scans

## Data Access

Uses the UFDC Patron API at `api.patron.uflib.ufl.edu`:
- Serial hierarchy endpoint lists all issues
- Citation endpoint provides metadata
- Pagetext endpoint returns OCR full text per page
