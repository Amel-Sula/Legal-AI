# HT/JuricafCassation — Haiti Court of Cassation Decisions (Juricaf)

Haitian Cour de Cassation decisions from the AHJUCAF Juricaf database.

- **Source:** [Juricaf — Haiti](https://juricaf.org/recherche/+/facet_pays:Ha%C3%AFti)
- **Data type:** case_law
- **Language:** French
- **Coverage:** ~121 decisions (2011–2014)
- **Method:** Juricaf JSON API + HTML full text extraction
