# BD/BSEC — Bangladesh Securities & Exchange Commission

Securities laws, rules, regulations, directives, orders, and circulars from the Bangladesh Securities and Exchange Commission (BSEC).

**URL:** https://sec.gov.bd/home/laws
**Data type:** legislation, doctrine
**Coverage:** 1969–present (Securities and Exchange Ordinance through current regulations)

## How it works

1. Scrapes the BSEC laws listing page for PDF links
2. Downloads each PDF document
3. Extracts text using pdfminer (or fallback regex extraction)
4. Normalizes into standard schema with full text
