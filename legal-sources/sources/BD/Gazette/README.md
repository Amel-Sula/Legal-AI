# BD/Gazette — Bangladesh Government Press Gazette Archive

Official gazette archive from the Bangladesh Government Press (BG Press),
containing weekly and extraordinary gazettes with statutory notifications,
rules, orders, appointments, and court notices.

- **Source**: https://www.dpp.gov.bd/bgpress/index.php/document/gazettes/140
- **Type**: legislation (gazette)
- **Records**: ~50,713
- **Language**: Bengali (bn)
- **Format**: PDF (text-based, not scanned)

## Coverage

- **Weekly gazettes**: Multi-part publications with statutory notifications,
  appointments, court notices, etc.
- **Extraordinary gazettes**: Individual publications for urgent matters.

## Data Access

The archive is an HTML listing with pagination. Each gazette links to an
intermediate page containing PDF download links. PDFs are text-based Bengali
documents using SutonnyMJ and NikoshBAN fonts.
