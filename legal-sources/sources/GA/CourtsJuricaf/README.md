# GA/CourtsJuricaf — Gabon Courts (Juricaf)

Gabon court decisions via [Juricaf](https://juricaf.org),
the francophone court decisions database operated by AHJUCAF.

## Data

- **Type:** case_law
- **Format:** JSON (search API) + HTML (full text from decision pages)
- **Language:** French
