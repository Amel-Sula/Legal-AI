# GA/JournalOfficiel — Journal Officiel de la République Gabonaise

Official Gazette of the Gabonese Republic. Publishes laws, decrees, ordinances, arrêtés, and regulatory texts.

- **URL**: https://journal-officiel.ga
- **Language**: French
- **Coverage**: 1984–present
- **Data type**: legislation
- **Auth**: none (open public access)

## Method

HTML scraping of individual document pages. Documents are accessible at sequential URL IDs (`/{id}-x/`). Full text is extracted from the HTML body between `</nav>` and `<footer>` tags.
