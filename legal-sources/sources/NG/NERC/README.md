# NG/NERC

Nigerian Electricity Regulatory Commission — Orders & Regulations.

600+ regulatory documents including tariff orders (MYTO), regulations, grid/distribution/metering
codes, guidelines, and market rules for Nigeria's electricity supply industry.

**Data**: PDF documents from WordPress-based document library with paginated categories.

**Method**: Scrape category listing pages for PDF links, download each PDF, extract text via pdfplumber.

**Categories**: orders, regulations, codes, guidelines-standards, market-documents.
