# NG/NAICOM — National Insurance Commission of Nigeria

Regulatory documents from NAICOM: circulars, guidelines, laws, bulletins, and publications.

## Data types

- **doctrine**: Regulatory circulars, guidelines, laws, market bulletins, publications

## Strategy

WordPress REST API at `naicom.gov.ng/wp-json/wp/v2`:
- **Media API**: 57 PDF attachments downloaded and text extracted via pdfplumber
- **Posts API**: Inline-text posts (news, press releases) with HTML stripped
- Categories: circulars, guidelines, laws, bulletins, annual reports, publications
