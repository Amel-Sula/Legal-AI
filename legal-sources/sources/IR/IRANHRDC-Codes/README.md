# IR/IRANHRDC-Codes — Iran Human Rights Documentation Center — Iranian Legal Codes

English translations of major Iranian legal codes published by the Iran Human Rights
Documentation Center (IHRDC), a US-based NGO.

## Coverage

- ~20 major legal codes and regulatory instruments
- Islamic Penal Code (Books I-V), Constitution, Civil Code
- Criminal Procedure Code, Press Law, Election Law
- Family Protection Law, Citizenship Rights Charter
- Language: English (translated from Persian/Farsi)

## Access Method

HTML scraping of WordPress site. Full text is embedded in article pages.
WP REST API is locked (401), so we scrape the HTML category listing.
