# IR/ABCenterLaws — Abdorrahman Boroumand Center Iranian Laws

English translations of major Iranian laws from the Abdorrahman Boroumand Center.

- **Source:** [iranrights.org — Laws Collection](https://www.iranrights.org/library/collection/112/laws)
- **Data type:** legislation
- **Language:** English (translated from Persian/Farsi)
- **Coverage:** ~35 documents — Islamic Penal Code, Criminal Procedure, Civil Code, Constitution, etc.
- **Method:** HTML scraping — full text embedded in document pages
