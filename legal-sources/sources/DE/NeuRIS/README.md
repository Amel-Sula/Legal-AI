# DE/NeuRIS — German Federal Legal Information System

NeuRIS (Neues Rechtsinformationssystem) is the new unified German federal legal information portal, replacing the legacy platforms rechtsprechung-im-internet.de and gesetze-im-internet.de.

- **URL**: https://testphase.rechtsinformationen.bund.de/
- **API docs**: https://docs.rechtsinformationen.bund.de
- **Coverage**: 82,000+ federal court decisions, 2,400+ federal laws
- **Format**: REST/JSON API with HTML/XML content endpoints
- **Auth**: None required

## Data types

- **Case law**: Decisions from BVerfG, BGH, BVerwG, BAG, BSG, BFH, BPatG, and other federal courts
- **Legislation**: Federal laws and regulations (Bundesgesetze, Verordnungen)
