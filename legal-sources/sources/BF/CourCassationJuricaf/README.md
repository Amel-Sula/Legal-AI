# BF/CourCassationJuricaf — Burkina Faso Courts (Juricaf)

Court decisions from Burkina Faso via [Juricaf](https://juricaf.org), the portal of the
Association des Hautes Juridictions de Cassation des pays ayant en partage l'usage du français (AHJUCAF).

## Coverage

| Court | Decisions |
|-------|-----------|
| Cour d'appel | 98 |
| Cour de cassation | 92 |
| Cour de justice | 20 |
| **Total** | **210** |

## Data Access

- JSON search API: `https://juricaf.org/recherche/+/facet_pays:Burkina_Faso?format=json`
- Individual decision HTML: `https://juricaf.org/arret/{id}`
- Full text extracted from `div#textArret`
