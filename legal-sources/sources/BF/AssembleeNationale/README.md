# BF/AssembleeNationale

Burkina Faso Assemblée Nationale — Textes Législatifs (Promulgated Laws)

## Source

Official website of Burkina Faso's National Assembly (Assemblée législative de transition):
https://www.an.bf/loip

## Coverage

- **Type:** Legislation (promulgated laws)
- **Period:** 2018–present
- **Volume:** ~200+ laws
- **Format:** PDF full text extracted via pdfplumber
