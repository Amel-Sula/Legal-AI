# TL/MJ-LawsTL — Timor-Leste Laws (English Translations)

English translations of Timor-Leste legislation from the UNMIT Office of Legal Affairs archive.

## Coverage

- **RDTL Legislation** (2002–2012): Parliamentary Laws, Decree-Laws, Government Decrees, Ministerial Orders, Instructions, Resolutions, Presidential Decrees, Public Regulations, Constitution
- **UNTAET Legislation** (1999–2002): Regulations, Directives, Executive Orders, Notifications
- ~700 documents total as individual PDFs
- Language: English

## Data Source

Static HTML index at `mj.gov.tl/jornal/lawsTL/` with frameset-based navigation. Each category has a listing page (HTML table) with links to individual PDF files.
