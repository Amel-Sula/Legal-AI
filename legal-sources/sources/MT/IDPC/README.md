# MT/IDPC — Malta Information & Data Protection Commissioner

GDPR enforcement decisions issued by the Information and Data Protection
Commissioner (IDPC) of Malta. Covers data protection complaints, breach
notifications, and regulatory enforcement actions since 2022.

## Data

- **Type**: doctrine (GDPR enforcement decisions)
- **Records**: ~254 decisions
- **Full text**: PDF extraction where available; structured metadata for all
- **Fields**: year, type, description, outcome, corrective action

## Source

Decisions are published at https://idpc.org.mt/decisions/ in a table format
with PDF downloads for individual decision documents.
