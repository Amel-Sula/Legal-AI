# MT/MCCAA — Malta Competition and Consumer Affairs Authority

Competition decisions from the Office for Competition within the MCCAA.

## Coverage

- **Concentration decisions** (~133): Merger/acquisition clearances from 2011-2026
- **Antitrust decisions** (~9): Enforcement actions under the Competition Act

## Data Access

The MCCAA website (WordPress) renders decisions in HTML tables with `data-title`
and `data-link` attributes. Each decision links to a PDF document.

- Concentrations: `https://mccaa.org.mt/decisions/`
- Antitrust: `https://mccaa.org.mt/antitrust-decisions/`

Note: Some PDFs (typically short signed clearance letters) are scanned images
without extractable text. Only decisions with extractable text are included.
