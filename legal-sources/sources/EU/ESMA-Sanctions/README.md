# EU/ESMA-Sanctions — ESMA Sanctions Register

Administrative sanctions and measures imposed by EU national competent authorities (NCAs)
under MiFID, MAR, MAD, UCITS, AIFMD, EMIR, SFTR, BMR, CSDR, and other EU financial
legislation. Published by the European Securities and Markets Authority (ESMA).

## Data source

- **API**: Solr REST endpoint (no authentication required)
- **Endpoint**: `https://registers.esma.europa.eu/solr/esma_registers_sanctions/select`
- **Format**: JSON
- **Records**: ~1,377 enforcement sanctions
- **Coverage**: All EU/EEA member states
- **Full text**: Violation descriptions in original language
