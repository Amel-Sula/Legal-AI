# EU/EPPO — European Public Prosecutor's Office

Case information from EPPO covering investigations, indictments, asset seizures,
and convictions for crimes against the EU financial interests (VAT fraud, subsidy
fraud, corruption, money laundering).

- **Source**: https://www.eppo.europa.eu/en/news
- **Coverage**: ~870+ press releases from June 2021 to present
- **Access**: HTML scraping (no API available)
- **Data type**: case_law
