# TG/CourSupreme — Togo Courts (Juricaf)

Togo court decisions from the AHJUCAF Juricaf database.

**Source URL:** https://juricaf.org/recherche/+/facet_pays:Togo

## Coverage

- ~223 decisions (2005–2023)
- Cour suprême, Cour d'appel, Tribunal de première instance
- Full text in French

## Data Types

- `case_law` — Court decisions
