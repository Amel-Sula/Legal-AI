# TG/CourConstitutionnelle — Togo Constitutional Court Decisions

Decisions of the Cour Constitutionnelle du Togo (2005-2025).

- **Source**: https://courconstitutionnelle.tg
- **Format**: WordPress Download Manager + PDF
- **Coverage**: ~157 decisions
- **Language**: French
- **Data type**: case_law

## How it works

1. Paginates through the decisions category listing
2. Fetches each decision page to find PDF download URL
3. Downloads PDF and extracts text via pypdf
4. Only includes decisions where text extraction yields 50+ characters
