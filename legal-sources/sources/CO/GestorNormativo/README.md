# CO/GestorNormativo — Colombia Gestor Normativo (Función Pública)

Comprehensive repository of Colombian norms maintained by Función Pública.
Covers laws, decrees, sentencias, resolutions, circulars, conceptos, and other
regulatory instruments. ~41K documents with full HTML text.

**URL:** https://www.funcionpublica.gov.co/eva/gestornormativo/

## Data Access

- Search API enumerates norm IDs by document type via `funajax.php`
- Individual norm pages at `norma.php?i={id}` contain full text
- No authentication required
