# MC/CourtsJuricaf — Monaco Court Decisions (Juricaf)

Monaco court decisions fetched from [Juricaf](https://juricaf.org), the francophone
supreme court decisions database maintained by AHJUCAF.

Covers: Tribunal suprême, Cour de cassation, Cour d'appel, Tribunal de première instance.

~4,800+ decisions with full text in French.
