# PG/NationalGazette — Papua New Guinea National Gazette

Papua New Guinea National Gazette compilations via the [PNGi Portal](https://pngiportal.org/) S3 bucket.

## Coverage

- **Gazette compilations:** ~154
- **Period:** 1975–2024
- **Language:** English
- **Content:** Assented Acts, statutory rules, government notices

## Data Source

- **S3 bucket:** `downloads.pngiportal.org.s3.amazonaws.com`
- Gazette directories listed via S3 `list-type=2&prefix=NG&delimiter=/`
- Full OCR text from `pages.json` in each directory
- Published weekly on Thursdays, "Published by Authority"
