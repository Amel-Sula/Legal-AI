# PW/FIC-Regulations — Palau Financial Institutions Commission

Laws and prudential regulations from the Republic of Palau Financial Institutions
Commission (ROPFIC). Covers banking, superannuation, AML/CFT, and corporate
regulations.

## Data

- **Type**: legislation
- **Documents**: ~20 (5 laws + 11 prudential regulations + 4 other regulations)
- **Format**: PDF → extracted text
- **Language**: English
