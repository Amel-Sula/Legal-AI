# CL/Aduanas — Servicio Nacional de Aduanas

Chilean National Customs Service legal documents.

## Data Sources

1. **Compendio de Normas Aduaneras** — 7 consolidated chapters of customs legislation (full HTML text)
2. **Resoluciones Anticipadas** — advance rulings on tariff classification (full HTML text, discovered via sitemaps)
3. **Oficios Circulares** — administrative circular letters (PDF extraction)
4. **Dictámenes de Clasificación** — classification rulings 1993-2009 (PDF extraction)

## Coverage

- Compendio: consolidated customs law (continuously updated)
- Resoluciones Anticipadas: ~20+ per year (2024-present in sitemaps)
- Oficios Circulares: ~70-100 per year (2007-2026)
- Dictámenes: ~1993-2009
