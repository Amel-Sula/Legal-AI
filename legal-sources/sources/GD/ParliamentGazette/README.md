# GD/ParliamentGazette — Grenada Government Gazette (Parliament)

Grenada Government Gazette documents from the Grenada Parliament website.

**Source URL:** https://grenadaparliament.gd/cat_doc/the-grenadian-government-gazette/

## Coverage

- ~157 documents (2023–2026)
- Acts, Statutory Rules & Orders (SROs), gazette issues
- Full text in English, extracted from PDFs

## Data Types

- `legislation` — Acts, SROs, and gazette notices
