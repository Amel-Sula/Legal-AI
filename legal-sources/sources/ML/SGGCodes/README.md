# ML/SGGCodes — Mali Consolidated Legal Codes (SGG)

**Source:** [sgg-mali.ml](https://sgg-mali.ml/fr/journal-officiel/les-codes-consolides.html)
**Type:** legislation
**Records:** 21 consolidated legal codes
**Language:** French

## Overview

The Secrétariat Général du Gouvernement (SGG) of Mali publishes consolidated versions of the country's major legal codes as downloadable PDF documents. This includes the Penal Code, Civil Procedure Code, Labor Code, Mining Code, Electoral Code, and 16 others.

## Data Access

- **Method:** HTML page scraping + PDF download and text extraction
- **Auth:** None required
- **Format:** PDF documents
- **URL pattern:** `https://sgg-mali.ml/codes/{filename}.pdf`
