# ML/CourtsJuricaf — Mali All Courts Decisions (Juricaf)

Mali court decisions from the Juricaf database (AHJUCAF francophone supreme court decisions).

Covers decisions from multiple Malian courts including:
- Cour d'appel de Bamako
- Cour suprême
- Other courts

~1,138 decisions available with full text in French.
