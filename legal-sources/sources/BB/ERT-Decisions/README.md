# BB/ERT-Decisions — Barbados Employment Rights Tribunal Decisions

Employment Rights Tribunal decisions published by the Barbados Ministry of Labour.

- **Coverage**: 2015–present
- **Type**: case_law (unfair dismissal, discrimination, redundancy, employment disputes)
- **Source**: https://labour.gov.bb/employment-rights-tribunal-2/
- **Format**: PDF documents via WordPress Download Manager
- **Note**: Older decisions (2015–2020) have digital text; newer ones (2022+) are scanned images and are automatically skipped.
