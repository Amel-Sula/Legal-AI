# BB/ParliamentLaws — Barbados Parliament Laws & Statutory Instruments

Consolidated statutes and subsidiary legislation from the Barbados Parliament website.

- **URL:** https://www.barbadosparliament-laws.com/en
- **Data type:** legislation
- **Records:** ~623 consolidated statutes + ~545 acts + ~1936 statutory instruments
- **Format:** PDF (text extraction via pdfminer)

The site uses AJAX endpoints to serve paginated listings. Each document has a
direct PDF URL at `/uploads/Barbados-cs/` (consolidated statutes) or
`/uploads/Barbados-act/` (acts).
