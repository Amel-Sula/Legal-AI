# CY/CyLII — Cyprus Legal Information Institute (CyLaw)

Consolidated Cypriot legislation and Supreme Court case law from [CyLaw](https://www.cylaw.org), the Cyprus Legal Information Institute (CyLII/KINOP).

## Coverage

- **Legislation**: ~1700 consolidated laws (Greek)
- **Case Law**: Supreme Court decisions from 1961 to present

## Data Source

- **Legislation**: Static HTML at `cylaw.org/nomoi/enop/non-ind/{law}/full.html`
- **Case Law**: Year indexes at `cylaw.org/apofaseis/aad/index_{year}.html`, documents via CGI script
- **Encoding**: Windows-1253 (Greek)
