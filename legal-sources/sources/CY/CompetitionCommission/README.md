# CY/CompetitionCommission

Cyprus Commission for the Protection of Competition (CPC / Επιτροπή Προστασίας Ανταγωνισμού)

## Overview

Competition decisions from the Cyprus CPC, covering:
- **Mergers** (concentrations / συγκεντρώσεις)
- **Cartels / Collusions** (συμπράξεις)
- **Dominant Position** abuse (δεσπόζουσα θέση)
- **Economic Dependence** (οικονομική εξάρτηση)

~421 decisions available. Full text extracted from PDF attachments on a Lotus Domino/Notes backend. Most decisions are in Greek; some merger clearances have English versions.

## Data Source

- **Website:** https://www.competition.gov.cy
- **Backend:** IBM Lotus Domino/Notes (`.nsf` database)
- **Format:** HTML listing pages → individual document pages → PDF attachments
- **Language:** Greek (primary), English (some merger decisions)
