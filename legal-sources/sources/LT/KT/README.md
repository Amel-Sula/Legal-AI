# LT/KT — Lithuanian Competition Council (Konkurencijos taryba)

Decisions of the Lithuanian Competition Council, the state authority
implementing competition policy and supervising compliance with the
Law on Competition.

## Coverage

- **Period**: 1999–present
- **Types**: Antitrust decisions, merger reviews, abuse of dominance,
  public entities, state aid, advertising, retail trade
- **Language**: Lithuanian
- **Volume**: ~2,000+ decisions across 173+ pages

## Data Access

Decisions are listed on paginated HTML pages at
`https://kt.gov.lt/lt/dokumentai` and published as individual PDFs.
The scraper parses the listing pages and downloads each PDF for
full-text extraction via pdfplumber.
