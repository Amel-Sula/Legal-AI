# RS/SupremeCourtPractice — Serbia Supreme Court Practice Database (VKS)

Court practice database of the former Supreme Court of Cassation (Vrhovni kasacioni sud, VKS) of Serbia. Contains ~29,500+ selected and classified decisions from the pre-2022 era.

Complements RS/SupremeCourt which covers post-2022 decisions (court_type=sc).

- **Source**: https://www.vrh.sud.rs/en/court-practice-database
- **Data type**: case_law
- **Language**: Serbian (Latin script)
- **Method**: SOLR search (court_type=vks) + Drupal 7 detail page scraping
- **Auth**: none
