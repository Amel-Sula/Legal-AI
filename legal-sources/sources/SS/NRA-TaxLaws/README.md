# SS/NRA-TaxLaws

South Sudan tax and customs legislation from the National Revenue Authority (NRA/SSRA).

## Data

- **Type**: legislation
- **Format**: Strapi CMS JSON API → PDF download → text extraction
- **Coverage**: Taxation Acts (2009–2021), Finance Acts (2012–2025), Customs Acts, NRA/SSRA Acts
- **Volume**: ~14 legal documents with full text
- **API**: `https://cms.nra.gov.ss/resources`
