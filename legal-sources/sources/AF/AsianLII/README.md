## Why this source is blocked

**Category:** Cloudflare JS challenge

**Technical reason:** `cloudflare_js_challenge`

**Details:** AsianLII (and its sister sites WorldLII, CommonLII) are behind Cloudflare managed JS challenges. All return HTTP 403 without JavaScript execution. The INTL/AsianLII source is also blocked for the same reason. Requires browser automation (Playwright/Selenium) to bypass.

- If AsianLII provides an API or removes the Cloudflare challenge, please let us know
