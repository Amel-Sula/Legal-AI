# IL/Versa-SupremeCourt

Israeli Supreme Court decisions in English translation, from the Cardozo Israeli Supreme Court Project at Benjamin N. Cardozo School of Law, Yeshiva University.

- **URL**: https://versa.cardozo.yu.edu/opinions
- **Type**: case_law
- **Language**: English (translations of Hebrew originals)
- **Records**: ~419 opinions (1940–2026)
- **Coverage**: Constitutional Law, Administrative Law, Criminal Law, Family Law, and more

## How it works

1. Discovers all opinion URLs from the site map page
2. Scrapes each opinion page for metadata (case number, date, topics, abstract) and full text
3. Strips HTML and normalizes into standard schema
