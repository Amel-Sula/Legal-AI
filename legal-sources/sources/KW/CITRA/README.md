# KW/CITRA — Kuwait Communication & IT Regulatory Authority

Regulations, decisions, resolutions, and policies issued by CITRA (formerly
the Ministry of Communications). Covers data privacy, cloud computing,
cybersecurity, frequency spectrum, numbering plans, device approval, and
telecommunications licensing.

## Data

- ~50 PDF documents across the regulations listing and law directory
- Some PDFs are scanned images — only text-based PDFs are ingested
- Typically 10-30 text-based documents with extractable full text
