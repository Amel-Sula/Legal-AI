# EC/CNJ-Precedentes

**Corte Nacional de Justicia — Binding Jurisprudential Precedents (Ecuador)**

Mandatory binding precedents issued under Ecuador's triple-reiteration rule (Art. 184-185 Constitution). These are the highest-authority case law decisions, binding on all lower courts.

- **Source**: https://www.cortenacional.gob.ec/cnj/index.php/resoluciones-a/precedentes-jurisprudenciales
- **Coverage**: 2009–present (~60+ resolutions)
- **Format**: PDF (direct download links)
- **Language**: Spanish
