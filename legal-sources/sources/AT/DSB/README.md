# AT/DSB — Austrian Data Protection Authority (Datenschutzbehörde)

GDPR enforcement decisions by Austria's Data Protection Authority, published through the RIS OGD API v2.6.

- **Records**: ~1,854 decisions
- **Coverage**: 1990s (DSK era) through present-day GDPR enforcement
- **Language**: German
- **Data type**: doctrine (regulatory decisions)
- **API**: RIS OGD API v2.6 — `Dsk` application, no auth required
