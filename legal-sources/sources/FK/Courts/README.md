# FK/Courts - Falkland Islands Court Decisions

Fetches court judgments from the Falkland Islands Courts & Tribunals Service.

## Coverage

- **Civil** judgments (Supreme Court, Magistrate's Court, Court of Appeal) — ~22 decisions
- **Criminal** sentencing remarks and judgments — ~41 decisions
- **Coroner** inquest findings — ~40 decisions
- Date range: 1864–2026

## Data Access

Judgments are published as PDFs on the official government website.
No API available — HTML scraping of listing pages + PDF text extraction.
