# TR/Sayistay — Turkish Court of Accounts (Sayıştay)

Supreme audit institution of Turkey with judicial authority over public financial management.

## Data Source

- **URL**: https://www.sayistay.gov.tr
- **Type**: case_law
- **Method**: DataTables server-side API + HTML detail pages
- **Auth**: None required

## Coverage

Three decision bodies:

| Body | Turkish Name | Decisions |
|------|-------------|-----------|
| Daire | Yargılama Dairesi | ~22,000 |
| Temyiz Kurulu | Temyiz Kurulu | ~29,000 |
| Genel Kurul | Genel Kurul | ~1,000+ |
