# TR/BDDK — Turkish Banking Regulation and Supervision Agency

Banking regulations, communiques, board decisions, and supervisory guidance from BDDK (Bankacılık Düzenleme ve Denetleme Kurumu).

## Data Source

- **Website:** https://www.bddk.org.tr/Mevzuat
- **Format:** Server-rendered HTML category pages + PDF documents
- **Auth:** None required
- **Coverage:** ~1,100+ documents including regulations, circulars, guides, and board decisions

## Data Types

- `doctrine` — banking regulatory guidance, communiques, board decisions
