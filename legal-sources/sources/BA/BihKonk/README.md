# BA/BihKonk — Competition Council of Bosnia and Herzegovina

Decisions of the Competition Council of BiH (Konkurencijsko vijeće BiH / Конкуренцијски савјет БиХ).

## Coverage

- **Types**: Concentrations, prohibited agreements, abuse of dominant position, other competition decisions
- **Period**: 2005–present
- **Volume**: ~672 decisions
- **Languages**: Bosnian, Serbian, Croatian (English translations for select decisions)

## Data Access

WordPress REST API at `/wp-json/wp/v2/posts` with category filters. Decisions are published as embedded PDFs; full text is extracted via pdfplumber/pypdf.
