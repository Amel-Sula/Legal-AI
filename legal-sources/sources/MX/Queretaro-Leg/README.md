# MX/Queretaro-Leg — Querétaro State Legislature Laws & Codes

Consolidated laws, codes, organic laws, and the state constitution of
Querétaro from the LXI Legislatura website. ~130 PDF documents across
three categories.

## Data

| Field    | Description                    |
|----------|--------------------------------|
| title    | Official law/code name         |
| text     | Full text extracted from PDF   |
| category | Leyes / Códigos / Leyes Orgánicas |
| url      | Direct PDF download link       |
