# ZM/ZRA-PracticeNotes

Zambia Revenue Authority — Practice Notes

Annual tax practice notes published by the Zambia Revenue Authority (ZRA) since 2002. These documents explain changes to tax legislation, new rates and thresholds, compliance procedures, and administrative guidance.

## Coverage

- **Years**: 2002–2024
- **Topics**: Income Tax, VAT, PAYE, Excise Duty, Customs, Property Transfer Tax, Turnover Tax, Withholding Tax, Mineral Royalty, Insurance Premium Levy
- **Format**: PDF documents with extractable text
- **Count**: ~32 documents (annual compilations + individual topic notes)

## Data Access

Documents are hosted on the ZRA WordPress site and indexed via the WP REST API:
- Media endpoint: `GET /wp-json/wp/v2/media?search=practice+note&media_type=application`
- PDFs at: `https://www.zra.org.zm/wp-content/uploads/...`
