# ZM/Judiciary — Zambia Judiciary Court Decisions

Official court decisions from the Judiciary of Zambia, covering:
- **Supreme Court** (~282 decisions)
- **Constitutional Court** (~224 decisions)
- **Court of Appeal** (~1,048 decisions)
- **High Court** (~1,596 decisions)

## Data Access

Decisions are published on the official Zambia Judiciary website (judiciaryzambia.com)
as WordPress posts with attached PDF documents. The WP REST API provides structured
metadata (title, date, categories), while full text is extracted from the PDFs.
