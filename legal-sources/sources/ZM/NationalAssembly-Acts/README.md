# ZM/NationalAssembly-Acts — Zambia National Assembly Acts of Parliament

Official Acts of Parliament (2005–2026) from the National Assembly of Zambia.
Approximately 960+ acts with PDF full text extraction via pdfminer.

## Data access

HTML scraping of Drupal listing at `/acts-of-parliament`, paginated (~49 pages).
Each act links to a node page with a PDF attachment. PDFs have extractable text layers.
