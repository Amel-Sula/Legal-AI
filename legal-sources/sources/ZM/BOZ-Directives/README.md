# ZM/BOZ-Directives — Bank of Zambia Regulatory Framework

Directives, circulars, regulations, acts, guidelines, and orders from the Bank of Zambia (BOZ).

**Source:** https://www.boz.zm/
**Documents:** ~646 regulatory framework PDFs
**Categories:** Acts of Parliament, Related Acts, Regulations, Rules, Directives, Guidelines, Circulars, Orders

## How it works

The BOZ website is an Angular SPA, but the backend uses Drupal with JSON:API exposed at `/jsonapi/node/regulatory_framework`. Each document has an attached PDF (`field_regulatory_file`). PDFs are served from `/sites/default/files/`.
