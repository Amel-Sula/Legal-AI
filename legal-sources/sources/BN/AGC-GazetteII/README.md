# BN/AGC-GazetteII — Brunei Government Gazette Part II

Subsidiary legislation, orders, notifications, and regulations published in
the Government Gazette Part II by Brunei's Attorney General's Chambers.

- **Coverage:** 1998–2026 (~500+ items)
- **Language:** English (Malay versions available but not fetched)
- **Format:** PDFs → full text extraction
- **Update frequency:** Ongoing publications throughout each year

## Source

SharePoint-based listing at the AGC website. Each year links to a page
containing gazette items with English and Malay PDF downloads.
