# BN/AITI-Legislation

Brunei AITI — Info-communications Technology Legislation.

32 legislation documents covering telecom, broadcasting, data protection, e-transactions,
and postal services in Brunei Darussalam. PDFs hosted on the Attorney General's Chambers (AGC) website.

**Data**: ~32 PDF gazette documents linked from the AITI reference page.

**Method**: Parse AITI listing page for PDF links, download from agc.gov.bn, extract text via pdfplumber.
