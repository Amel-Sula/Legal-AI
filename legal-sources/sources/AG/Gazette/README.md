# AG/Gazette — Antigua and Barbuda Official Gazette

Weekly Official Gazette of Antigua and Barbuda. PDFs are exposed via the
site's WordPress REST API (`/wp-json/wp/v2/media`) — 800+ issues with
extractable text covering statutory instruments, parliamentary notices,
appointments, electoral notices, and other official publications.

## Source

- **URL:** http://gazette.laws.gov.ag/
- **API:** http://gazette.laws.gov.ag/wp-json/wp/v2/media
- **Format:** PDF (text-based, extractable with PyMuPDF)
- **Coverage:** Multi-year archive, weekly issues
- **Discovery:** Media endpoint enumerates every uploaded gazette PDF
