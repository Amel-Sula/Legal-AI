# LR/SupremeCourt — Liberia Supreme Court Opinions

Supreme Court opinions, decisions, orders, and special master reports from the
Judiciary of the Republic of Liberia.

- **Source:** https://judiciary.gov.lr
- **Coverage:** ~400+ documents (2014–2026)
- **Language:** English
- **Data type:** case_law
- **Method:** WP REST API + PDF text extraction (pdfminer)
