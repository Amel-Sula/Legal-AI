# SE/Finansinspektionen — Swedish Financial Supervisory Authority Sanctions

Sanctions and enforcement decisions from Finansinspektionen (FI), Sweden's
financial supervisory authority.

- **Coverage:** ~1,370 decisions from 2002–2026
- **Categories:** Financial firms, market abuse, market information, unlicensed firms, financial reporting
- **Language:** Swedish
- **Update frequency:** Ongoing as new decisions are published
- **Data type:** doctrine
- **Access method:** HTML scraping + PDF extraction
