# VU/CourtsJudgments — Vanuatu Judiciary Judgments Database

**Source:** [courts.gov.vu](https://courts.gov.vu/court-activity/judgments)

Judgments from the Vanuatu judiciary including Court of Appeal, Supreme Court,
Island Court, and Magistrate's Court. Approximately 2,698 judgments from 2017
onwards, with full text.

## Data Types

- **case_law** — Court judgments with full text

## Coverage

- Court of Appeal, Supreme Court, Island Court, Magistrate's Court
- Criminal, Civil, Customary Land, Judicial Review cases
- From 2017 to present
- English language
