# VA/CodexIurisCanonici

1983 Code of Canon Law (Codex Iuris Canonici) promulgated by Pope John Paul II via the apostolic constitution *Sacrae disciplinae leges* on January 25, 1983.

Contains 1,752 canons organized in 7 books covering governance of the Latin Church. Both the official Latin text and English translation are fetched from vatican.va.

## Data

- **Type:** legislation
- **Records:** ~1,752 individual canons
- **Languages:** Latin (official), English (translation)
- **Coverage:** Complete 1983 Code (Books I–VII)

## Method

Static HTML scraping from vatican.va archive pages. Each Latin book is one page; English translations are split across ~40 sub-pages by title/section.
