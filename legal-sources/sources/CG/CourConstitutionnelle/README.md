# CG/CourConstitutionnelle — Congo-Brazzaville Constitutional Court

Decisions from the Cour Constitutionnelle de la République du Congo.

**Coverage:** Constitutional review decisions, advisory opinions, electoral dispute rulings since 2003.

**Method:** JSON API (`/api/documents`) → PDF download → text extraction (PyPDF2).

**Records:** ~54 documents (41 constitutional court decisions, 2 advisory opinions, plus historical decisions from the Conseil constitutionnel and Cour suprême).
