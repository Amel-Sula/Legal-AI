# GL/Courts — Greenland Court Decisions

Court decisions from Greenland's judiciary, accessed via Denmark's Domsdatabasen (court decisions database).

## Courts Covered

- **Grønlands landsret** — Greenland High Court (2nd instance)
- **Kujalleq Kredsret** — District court
- **Qeqqa Kredsret** — District court
- **Qaasuitsoq Kredsret** — District court

## Data Source

Greenland's courts are part of the Danish judiciary system. Domsdatabasen publishes anonymized court decisions from all Danish courts including Greenland since January 2022.

- **API**: REST JSON at `https://domsdatabasen.dk/webapi/api`
- **Coverage**: ~36 cases (database growing as courts digitize)
- **Language**: Danish (da)
