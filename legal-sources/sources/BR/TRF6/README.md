# BR/TRF6 — Tribunal Regional Federal da 6ª Região

Federal Regional Court for Minas Gerais (MG), created in 2022 when TRF-1's
jurisdiction was split. Uses the eproc2g jurisprudence portal (same system as TRF-4).

- **Type:** case_law
- **Language:** Portuguese
- **Volume:** ~77,000 decisions (acórdãos + decisões monocráticas)
- **Endpoint:** eproc2g.trf6.jus.br
