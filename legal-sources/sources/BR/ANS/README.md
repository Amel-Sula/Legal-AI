# BR/ANS — Agência Nacional de Saúde Suplementar

Brazil's National Supplementary Health Agency (ANS) legislation database.

Covers normative resolutions (RNs), operational resolutions (ROs), normative instructions (INs), portarias, and other regulatory acts governing private health insurance in Brazil.

~4,800 legislative acts from 1998 to present.

## Data Access

Full text is available via HTML pages at `ans.gov.br/component/legislacao/` with base64-encoded sequential numeric IDs. No authentication required.
