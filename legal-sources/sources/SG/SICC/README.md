# SG/SICC — Singapore International Commercial Court

Judgments from the Singapore International Commercial Court (SICC), a division of the Singapore High Court established in 2015 for international commercial disputes.

## Coverage

- **Case types**: International commercial disputes, arbitration, cross-border enforcement, contract disputes
- **Period**: 2015–present
- **Format**: HTML full text (no PDF extraction needed)
- **Volume**: ~242 judgments

## Data Access

Uses the eLitigation platform:
1. Paginate through `https://www.elitigation.sg/gdviewer/Home/Index?Filter=sicc&CurrentPage=N`
2. Parse HTML cards for case metadata (title, citation, date, case number)
3. Fetch individual judgment pages at `/gdviewer/sicc/{year}_{court}_{number}`
