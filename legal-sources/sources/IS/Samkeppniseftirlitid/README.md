# IS/Samkeppniseftirlitid — Icelandic Competition Authority

Samkeppniseftirlitið (the Icelandic Competition Authority) publishes decisions,
rulings, opinions, reports, and consultations on competition law matters.

- **Source**: https://www.samkeppni.is/urlausnir/
- **Records**: ~1,925 decisions (1994–2026)
- **Types**: Ákvarðanir (decisions), Úrskurðir (rulings), Umsagnir (opinions), Álit (advisory opinions), Skýrslur (reports)
- **Method**: Algolia search API (metadata) + PDF download (full text)
- **Language**: Icelandic
