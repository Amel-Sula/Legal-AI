# AX/Lagstiftning — Åland Islands Legislation (Ålex)

Consolidated legislation from the Åland Islands, an autonomous region of Finland with its own parliament (Lagtinget).

**Source:** [Ålands landskapsregering — Ålex](https://www.regeringen.ax/alandsk-lagstiftning/alex)

- ~517 consolidated laws (amendments incorporated into text)
- Swedish language
- Covers: landskapslagar, landskapsförordningar, republikens presidents förordningar
- Paginated HTML listing, individual law pages with structured HTML
