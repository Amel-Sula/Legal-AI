# GW/AssembleiaNacional

Guinea-Bissau National People's Assembly (Assembleia Nacional Popular) legislation portal.

Crawls the Plone CMS at [parlamento.gw/leis](https://www.parlamento.gw/leis) for the Constitution, laws, statutes, bylaws, and international treaties. Full text extracted from HTML; PDF fallback for documents only available as attachments.

**Coverage:** ~10 documents (Constitution, 4 laws, 2 statutes/bylaws, 3 treaties)
**Language:** Portuguese
**Data type:** legislation
