# GW/MEF-TaxLegislation

Guinea-Bissau Ministry of Economy & Finance — Tax Legislation via the Kontaktu portal.

Extracts full-text tax codes, ministerial decrees, and service instructions from the Semantic UI accordion at [kontaktu.mef.gw/legislation](https://kontaktu.mef.gw/legislation). All legislation is embedded in a single HTML page.

**Coverage:** 24 documents — 8 tax codes (Industrial Contribution, Urban Property, Capital Tax, Consumption Tax, IGV, Professional Tax, IVA, General Tax Law), ministerial decrees, orders, and service instructions.
**Language:** Portuguese
**Data type:** legislation
