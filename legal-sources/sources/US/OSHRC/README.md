# US/OSHRC — Occupational Safety & Health Review Commission

The Occupational Safety and Health Review Commission (OSHRC) is an independent
federal agency that adjudicates contests of OSHA citations and penalties. This
source collects both Final Commission Decisions and Final ALJ Decisions.

## Data access

- WordPress REST API: `https://www.oshrc.gov/wp-json/wp/v2/decisions`
- ~8,300+ decisions with HTML/PDF attachments
- Two categories: Final Commission Decisions (6,500+) and Final ALJ Decisions (1,800+)
- Full text extracted from HTML attachments via media API

## Coverage

- Decisions from 1971 to present
- Case law only (adjudicatory decisions on OSHA citation contests)
