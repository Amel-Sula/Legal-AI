# US/FinCEN-Enforcement

Financial Crimes Enforcement Network (FinCEN) enforcement actions — consent orders, civil money penalties, and assessments for violations of the Bank Secrecy Act (BSA).

- **Source**: https://www.fincen.gov/news/enforcement-actions
- **Type**: doctrine
- **Records**: ~131 enforcement actions (1999–present)
- **Format**: PDF documents extracted via pdfplumber
- **Access**: Direct HTTP, no authentication required

## Coverage

Two listing pages:
1. Main enforcement actions (consent orders, civil money penalties)
2. Enforcement actions for failure to register as a Money Services Business
