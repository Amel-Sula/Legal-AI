# US/NHTSA-Enforcement

National Highway Traffic Safety Administration (NHTSA) — Office of Defects Investigation (ODI)

Fetches defect investigation records via the public NHTSA JSON API. Covers preliminary evaluations, engineering analyses, and recall decisions for vehicle safety defects.

- **Records**: ~4,100+ investigations
- **API**: `api.nhtsa.gov/investigations` (no auth, JSON, paginated)
- **Content**: Full investigation descriptions with technical details
