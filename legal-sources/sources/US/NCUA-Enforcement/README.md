# US/NCUA-Enforcement — NCUA Administrative Orders

Enforcement actions from the **National Credit Union Administration (NCUA)** since 1991.

## Coverage

- **1,428 administrative orders** (as of May 2026)
- Cease-and-desist orders, prohibition orders, civil money penalties
- Actions against credit unions and affiliated individuals
- Period: 1991–present

## Data Source

- **CSV index**: Official downloadable CSV with all order metadata and URLs
- **Full text**: Newer orders (post-~2019) are HTML pages; older orders are PDFs
- Text extracted from both formats
