# US/OFAC-Enforcement

Office of Foreign Assets Control (OFAC) civil penalties and enforcement actions.

OFAC publishes settlement agreements, findings of violation, and penalty notices
for sanctions violations. Covers 2003–present with ~500+ enforcement actions
including full text extracted from PDF documents.

## Data

- **Type:** doctrine (enforcement actions, settlement agreements)
- **Format:** HTML tables with PDF document links
- **Coverage:** 2003–present
- **Records:** ~500+
