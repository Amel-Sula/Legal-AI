# SK/PMU — Slovakia Antimonopoly Office Decisions

Decisions from the Antimonopoly Office of the Slovak Republic (Protimonopolný úrad
Slovenskej republiky, PMÚ SR) — the central state administration body for the
protection and promotion of competition in Slovakia.

## Coverage

- **Types**: Cartels, abuse of dominance, concentrations (mergers), vertical agreements, other proceedings
- **Instances**: First instance and second instance (appeal) decisions
- **Language**: Slovak
- **Volume**: ~400+ decisions with PDF full text

## Data Source

- **List page**: https://www.antimon.gov.sk/prehlad-rozhodnuti/
- **Detail pages**: Individual case pages with metadata and PDF downloads
- **Format**: HTML scraping + PDF text extraction
