# SO/CBS — Central Bank of Somalia: Regulations

Banking regulations, governance guidelines, AML/CFT legislation, and licensing
requirements published by the Central Bank of Somalia.

## Data access

PDF links are scraped from the `/regulatory-guidelines/` page.  Text is
extracted with PyMuPDF (fitz).  The site requires a browser-like User-Agent
header (bare curl gets 403).

## Coverage

- **Period:** 2014–present
- **Volume:** ~40 PDF documents
- **Language:** English (some bilingual Somali/English)
- **Update cadence:** infrequent
