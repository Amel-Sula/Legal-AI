# IQ/CBI-Regulations — Central Bank of Iraq

Banking regulations, circulars, guidelines, and standards from the
[Central Bank of Iraq](https://cbi.iq/).

## Coverage

- **Circulars** (~600): Banking supervision directives, exchange licensing,
  capital adequacy standards, AML/CFT guidance, and reform documents.
  Paginated at `/news/section/77` (30 pages).
- **Guidelines & Standards** (~30): Standalone PDF documents covering
  corporate governance, ESG standards, financial literacy, consumer
  protection, and more from `/page/99`.

## Data access

HTML scraping of list pages + PDF text extraction via pdfplumber.
No API available. Content is primarily in Arabic with some English documents.
