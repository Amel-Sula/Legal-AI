# IN/AFT — Armed Forces Tribunal

Judgments and orders from the Armed Forces Tribunal (AFT), India.

## Coverage

- **Principal Bench**: New Delhi (~41K judgments, 2009–present)
- **Regional Benches**: Chennai (1.5K), Chandigarh (9.6K), Kochi (2.7K), Mumbai (1.4K), Srinagar (209), Jabalpur (47)
- **Total**: ~56K judgments
- **Case types**: OA (Original Application), TA (Transfer Application), AT, CA (Civil Appeal), RA (Review Application), MA (Miscellaneous Application), WP(C)
- **Departments**: Army, Navy, Air Force

## Data Sources

- **Metadata**: `http://aftpb.org/aft/` — PHP web application with paginated listing (principal bench) and JSON API (regional benches)
- **Full text PDFs**: `https://aftdelhi.nic.in/assets/judgement/...` and `https://aftdelhi.nic.in/benches/...`

## Notes

- `aftdelhi.nic.in` may be unreachable from non-Indian IPs (NIC infrastructure)
- `aftpb.org` is accessible worldwide for metadata
- PDF text extraction via pdfplumber
