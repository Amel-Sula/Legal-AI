# IN/IndiaCode-StateActs — India Code: State & UT Acts

Indian **state and union-territory legislation** (acts) with full text from the
[India Code](https://www.indiacode.nic.in/handle/123456789/2180) digital
repository (indiacode.nic.in), "State Act" community. Covers ~35 states/UTs.

Full text comes from section-level HTML where available, otherwise from the
attached (English) PDF bitstream.

## Usage

```bash
python bootstrap.py test                 # connectivity check
python bootstrap.py bootstrap --sample   # fetch sample records
python bootstrap.py bootstrap            # full pull
```
