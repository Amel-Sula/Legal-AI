# IN/LokSabhaDebates — Lok Sabha Debate Transcripts

Indian Parliament Digital Library debate transcripts from the Lok Sabha (House of the People).

- **Coverage:** 1st–18th Lok Sabha (1952–present), ~6,650 debate sessions
- **Type:** Doctrine (parliamentary debate transcripts)
- **Language:** English (original version)
- **API:** DSpace 7 REST API on `elibrary.sansad.in`
- **Full text:** Pre-extracted by DSpace Tika filter (TEXT bundle)
