# IN/PRSLegislative — PRS Legislative Research Bill Tracking

PRS Legislative Research is an independent research institute that tracks bills introduced in India's Parliament. This source provides full summary/analysis text for ~960 bills from 1993 to present.

## Data Coverage

- **Type**: Legislation (bill summaries and analysis)
- **Period**: 1993–present
- **Language**: English
- **Records**: ~960 bills
- **Content**: Full PRS analysis text including key features, issues for consideration, and legislative context
