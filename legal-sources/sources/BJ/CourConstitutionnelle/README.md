# BJ/CourConstitutionnelle — Benin Constitutional Court

Decisions from the Cour Constitutionnelle du Bénin (Constitutional Court of Benin).

## Coverage

- **Period**: 1993–present
- **Volume**: ~7,450 decisions
- **Types**: DCC (ordinary), EL (legislative electoral), EP (presidential electoral), EG (general electoral)
- **Language**: French
- **Full text**: Extracted from PDF via PyMuPDF

## Method

1. Paginated listing from `courconstitutionnelle.bj/fr/decisions?page=N`
2. PDF download from `/files/decisions/{ID}_{date}.pdf`
3. Text extraction via PyMuPDF (fitz)

Note: ~10-15% of older decisions are scanned (image-only) PDFs with no extractable text — these are skipped.
