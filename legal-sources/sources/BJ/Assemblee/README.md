# BJ/Assemblee — Benin National Assembly Laws

Laws of the Republic of Benin from the National Assembly's Documentation and Archives
Service. Published via an Omeka S platform with a REST API for structured metadata
and PDF downloads.

- **Coverage:** 1960–present
- **Language:** French
- **Volume:** 1172+ laws
- **Format:** PDF with text extraction via pdfplumber (~90% success rate)
- **API:** Omeka S REST API (`/api/items`, `/api/media/{id}`)
- **Data type:** legislation
