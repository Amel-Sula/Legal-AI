# AL/EURALIUS — Albanian Legislation (English Translations)

**Source:** [EURALIUS](https://euralius.eu/index.php/en/library/albanian-legislation)
**Country:** Albania (AL)
**Type:** Legislation
**Language:** English
**Records:** ~100-150 documents across 54 legal categories

## Overview

EURALIUS (European Assistance Mission to the Albanian Justice System) is an
EU-funded project supporting judicial reform in Albania. It publishes official
English translations of key Albanian legislation including:

- Constitution of the Republic of Albania
- Civil Code & Civil Procedure Code
- Criminal Code & Criminal Procedure Code
- Administrative Procedure Code
- Electoral Code, Labour Code
- Anti-corruption, anti-mafia legislation
- Justice reform laws
- Data protection, consumer protection

## Data Access

Documents are published as PDFs via jDownloads (Joomla component).
The bootstrap script crawls categories, discovers download links,
fetches PDFs, and extracts text via pdfplumber/PyPDF2.
