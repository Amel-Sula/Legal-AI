# CZ/CourtsJuricaf — Czech Republic All Courts Decisions (Juricaf)

Czech court decisions from the AHJUCAF francophone court decisions database
via juricaf.org. ~59 decisions available.

## Data

- **Type:** case_law
- **Language:** French
- **Source:** Juricaf / AHJUCAF (Association des Hautes Juridictions de Cassation des pays ayant en partage l'usage du français)
- **Access:** JSON API (paginated search) + HTML detail pages with full text
