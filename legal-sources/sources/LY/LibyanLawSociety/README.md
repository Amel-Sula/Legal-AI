# LY/LibyanLawSociety

Libyan Law and Society — Leiden/Benghazi Academic Collection.

17 hard-to-find Libyan legal documents from the collaboration between
Benghazi Centre for Law and Leiden University. Constitutional declarations
(1951, 1969, 1977, 2011), transitional justice laws, decrees, and reports.

**Method:** PDF download + text extraction via pdfplumber.

## Usage

```bash
python bootstrap.py test                  # Test connectivity
python bootstrap.py bootstrap --sample    # Fetch 12 sample records
python bootstrap.py bootstrap --full      # Full bootstrap (all 17 docs)
```
