# INTL/COMESACourt-AfricanLII

COMESA Court of Justice decisions via AfricanLII.

~45 judgments (2001-2025) covering trade disputes, human rights, and institutional matters across 21 COMESA member states. Full text extracted from judgment PDFs hosted on AfricanLII.

This source bypasses the scanned PDF issue on the official comesacourt.org by using AfricanLII's digitized copies.
