# INTL/LCIA-ChallengeDecisions — LCIA Arbitrator Challenge Decisions

Publicly available arbitrator challenge decisions from the London Court of
International Arbitration (LCIA). 56 decisions from October 2010 to March 2022.

These are the only publicly available LCIA decisions — regular arbitral awards
remain confidential.

## Data access

Single HTML page with two tables of decisions. Each links to an individual PDF
via `/media/download.aspx?MediaId=NNNN`. PDFs have extractable text (pdfplumber).
