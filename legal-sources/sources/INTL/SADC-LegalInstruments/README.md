# INTL/SADC-LegalInstruments

SADC (Southern African Development Community) legal instruments: treaties, protocols, charters, declarations, memoranda of understanding, pacts, and regional codes & policies.

16 member states: Angola, Botswana, Comoros, DRC, Eswatini, Lesotho, Madagascar, Malawi, Mauritius, Mozambique, Namibia, Seychelles, South Africa, Tanzania, Zambia, Zimbabwe.

## Data source

- **URL**: https://www.sadc.int/
- **Categories**: `/sadc-treaty`, `/sadc-protocols`, `/charters`, `/declarations`, `/memoranda-of-understanding`, `/pacts`, `/regional-codes-policies`
- **Format**: HTML listing pages → document detail pages → PDF downloads
- **Text extraction**: pdfplumber
