# INTL/EACJ-AfricanLII

East African Court of Justice decisions via AfricanLII.

~390 judgments (2006-2026) covering trade, human rights, and institutional disputes across EAC member states (Burundi, DRC, Kenya, Rwanda, South Sudan, Tanzania, Uganda). Full text extracted from judgment PDFs hosted on AfricanLII.
