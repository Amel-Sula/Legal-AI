# INTL/ArcticCouncil-Docs

Arctic Council Open Access Archive — governance and treaty documents from the
intergovernmental forum for Arctic cooperation (1996-present).

## Data

- **Source:** DSpace 7.4 REST API at `oaarchive.arctic-council.org`
- **Documents:** ~3,165 items including binding agreements, ministerial
  declarations, SAO reports, and working group documents
- **Full text:** Pre-extracted text from PDFs available via DSpace TEXT bundle
- **API:** DSpace REST API (`/server/api/`) + OAI-PMH endpoint
