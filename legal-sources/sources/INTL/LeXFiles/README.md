# INTL/LeXFiles

**LeXFiles** — 5.8M English-language legal documents across 11 sub-corpora from 6 jurisdictions (EU, UK, US, Canada, India, ECtHR). 18.8B tokens total.

## Sub-corpora

| Corpus | Documents | Tokens |
|--------|-----------|--------|
| US Court Cases (CourtListener) | 4.6M | 11.4B |
| US Contracts (SEC/EDGAR) | 622K | 5.3B |
| US Legislation | 518 | 1.4B |
| EU Legislation (EUR-Lex) | 93.7K | 233.7M |
| UK Court Cases (BAILII) | 47K | 368.4M |
| UK Legislation | 52.5K | 143.6M |
| Indian Court Cases | 34.8K | 111.6M |
| EU Court Cases (CJEU) | 29.8K | 178.5M |
| ECtHR Cases (HUDOC) | 12.5K | 78.5M |
| Canadian Court Cases | 11.3K | 33.1M |
| Canadian Legislation | 6K | 33.5M |

## Source

- HuggingFace: https://huggingface.co/datasets/lexlms/lex_files
- Paper: Chalkidis et al., "LeXFiles and LegalLAMA", ACL 2023
- GitHub: https://github.com/coastalcph/lexlms
