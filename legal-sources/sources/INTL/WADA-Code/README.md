# INTL/WADA-Code — World Anti-Doping Agency Code and Standards

The World Anti-Doping Code is the core document harmonizing anti-doping policies, rules, and regulations across all sports and countries. It works in conjunction with eight mandatory International Standards.

## Documents Covered

| Abbrev | Document | Effective |
|--------|----------|-----------|
| WADC | World Anti-Doping Code | 2021-01-01 |
| ISCCS | International Standard for Code Compliance by Signatories | 2021-04-01 |
| ISE | International Standard for Education | 2021-01-01 |
| ISL | International Standard for Laboratories | 2021-01-01 |
| ISRM | International Standard for Results Management | 2021-01-01 |
| ISPPPI | International Standard for Protection of Privacy and Personal Information | 2021-01-01 |
| ISTI | International Standard for Testing and Investigations | 2023-01-01 |
| PL-2025 | Prohibited List 2025 | 2025-01-01 |
| PL-2026 | Prohibited List 2026 | 2026-01-01 |
| AG-2021 | Athlete's Guide to the 2021 Code | 2021-01-01 |

## Data Access

PDFs are downloaded from ITA.sport mirrors (the primary wada-ama.org site uses AWS WAF JavaScript challenges that block automated access). Fallback mirrors include FIVB and USADA.
