# INTL/EAEUCourt — Eurasian Economic Union Court Decisions

Decisions from the **Court of the Eurasian Economic Union (EAEU)** and historical **EurAsEC Court** cases at [courteurasian.org](https://courteurasian.org).

- ~113 EAEU cases (2015-present) + ~22 EurAsEC historical cases (2012-2014) = ~135 total
- Member states: Russia, Kazakhstan, Belarus, Armenia, Kyrgyzstan
- Language: Russian
- Full text extracted from PDF decisions via pdfplumber
- Case summaries and legal positions from HTML

## Data Access

- Sitemap: `sitemap-iblock-9.xml` provides all case URLs with lastmod dates
- Russian case pages contain structured metadata and case summaries
- Decision PDFs linked from each case page (download attribute)
- Site requires browser-like User-Agent (blocks generic UAs)
