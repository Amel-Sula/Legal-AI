# INTL/RSCSL — Residual Special Court for Sierra Leone

Decisions, judgments, and orders from the **Residual Special Court for Sierra Leone (RSCSL)** and its predecessor, the **Special Court for Sierra Leone (SCSL)**.

## Coverage

- **879 decisions** (as of July 2025)
- Cases: CDF, RUF, AFRC, Charles Taylor, Contempt
- Period: 2002–present
- Language: English

## Data Source

- **API**: Laravel DataTables JSON endpoint at `docs.rscsl.org`
- **Documents**: PDFs hosted on AWS S3
- **Full text**: Extracted from PDFs via pdfplumber
