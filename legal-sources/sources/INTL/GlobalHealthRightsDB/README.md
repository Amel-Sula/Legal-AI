# INTL/GlobalHealthRightsDB — Global Health & Human Rights Database

Case law from 122 countries relating to health and human rights.

- **Coverage:** ~1,850 cases from 122 countries
- **Language:** English (summaries and translations)
- **Update frequency:** Ongoing
- **Data type:** case_law
- **Access method:** WordPress sitemap + HTML scraping
