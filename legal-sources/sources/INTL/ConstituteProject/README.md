# INTL/ConstituteProject — World Constitutions

The [Constitute Project](https://www.constituteproject.org/) provides the full text of
232 national constitutions from ~200 countries, both current and historical versions.
Maintained by the Comparative Constitutions Project (University of Texas at Austin),
originally supported by Google Ideas.

## Data

- **Type:** Legislation (constitutions)
- **Volume:** ~232 constitutions
- **Languages:** English translations
- **Coverage:** Global — all UN member states plus territories
- **API:** JSON REST at `constituteproject.org/service` (no auth)
