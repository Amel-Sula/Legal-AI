# INTL/ColumbiaGFE — Columbia Global Freedom of Expression Case Law Database

Columbia University's Global Freedom of Expression initiative maintains a database of 3,400+ case analyses from 130+ countries covering freedom of expression issues from 1918 to present.

Each case entry includes structured metadata (court, date, outcome, themes, expression type) and extensive analysis (case summary, facts, decision overview, significance).

**Source:** https://globalfreedomofexpression.columbia.edu/

## Data Access

Cases are accessed via WordPress sitemap XMLs (`case-sitemap.xml` through `case-sitemap4.xml`). Individual case pages are scraped for metadata and full analysis text. The WP REST API does not expose the custom `case` post type.
