# INTL/GCC-LegalDocs

Gulf Cooperation Council — Digital Library. Official legal instruments of
the GCC Secretariat covering 6 Gulf states (SA, AE, KW, QA, BH, OM).

## Data

- **Source:** GCC Secretariat website at `gcc-sg.org`
- **Documents:** ~30 PDFs including economic agreements, unified regulations,
  human rights declaration, customs procedures, anti-dumping laws
- **Full text:** PDF extraction via pdfplumber
- **Access:** Direct PDF downloads from SharePoint digital library
