# INTL/GCF-Decisions — Green Climate Fund Board Decisions

**Source:** [https://www.greenclimate.fund/boardroom/decisions](https://www.greenclimate.fund/boardroom/decisions)
**Data types:** legislation, doctrine

Covers ~877 board decisions from the Green Climate Fund (2012–2026), including
funding approvals, governance policies, accreditation, and administrative decisions.
