# INTL/OPCW-Decisions

OPCW Conference of the States Parties (CSP) and Executive Council (EC) decisions.

- **Coverage:** CSP-1 (1997) to present, EC-1 to present
- **Document types:** Decision documents (DEC symbol prefix)
- **Records:** ~500+ decisions across 150+ sessions
- **Full text:** Extracted from official PDFs using PyMuPDF

## Data Source

Session listing pages at opcw.org contain HTML tables with document symbols,
titles, dates, and PDF links. The scraper discovers all session URLs, filters
for decision documents, downloads PDFs, and extracts full text.
