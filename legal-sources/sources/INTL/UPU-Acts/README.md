# INTL/UPU-Acts

Universal Postal Union — Acts and Convention Texts. Official legal instruments
of the intergovernmental postal organization (1964-present).

## Data

- **Source:** UPU website at `upu.int/en/universal-postal-union/about-upu/acts`
- **Documents:** ~70 PDFs including Constitution, Additional Protocols, General
  Regulations, Universal Postal Convention, Congress Acts, and Manuals
- **Full text:** PDF extraction via pdfplumber
- **Access:** Direct PDF downloads from HTML page
