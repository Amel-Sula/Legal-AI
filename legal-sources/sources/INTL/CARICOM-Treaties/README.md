# INTL/CARICOM-Treaties — Caribbean Community Treaty Collection

Treaties, protocols, and agreements from the CARICOM Secretariat covering the Caribbean Community and Common Market.

## Coverage

- **Founding treaties** — Treaty of Chaguaramas (1973), Revised Treaty of Chaguaramas (2001)
- **Protocols** — CSME, contingent rights, procurement, social security
- **Institutional agreements** — CCJ, CROSQ, CARPHA, CAHFSA, CDEMA, CDF, CCCCC
- **Trade agreements** — CARICOM-Cuba, double taxation, PICTA
- **Other** — arrest warrant treaty, CARIPASS, Georgetown Accord

## Data source

Treaty PDFs hosted at `caricom.org/wp-content/uploads/`. Full text extracted using pdfplumber.
