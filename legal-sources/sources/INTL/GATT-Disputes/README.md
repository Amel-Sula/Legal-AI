# INTL/GATT-Disputes

**GATT 1947 Dispute Settlement Database (WTO Archive)**

WTO interactive database of all 317 GATT dispute settlement cases from 1948-1995, with panel reports, working party reports, and procedural documents.

- **URL**: https://gatt-disputes.wto.org/
- **Language**: English
- **Coverage**: 1948–1995
- **Data types**: case_law
- **Format**: HTML dispute pages + PDF panel reports
