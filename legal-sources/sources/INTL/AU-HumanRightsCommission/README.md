# INTL/AU-HumanRightsCommission

**African Commission on Human and Peoples' Rights (ACHPR) — Decisions on Communications**

The ACHPR adjudicates individual complaints alleging violations of the African Charter on Human and Peoples' Rights. This source collects decisions on communications including findings on merits, admissibility rulings, strike-outs, and friendly settlements.

- **URL**: https://achpr.au.int/en/category/decisions-communications
- **Coverage**: ~400 decisions since 1988
- **Data type**: case_law
- **Method**: HTML listing scrape + PDF text extraction via pdfplumber
