# INTL/EBRD-Tribunal — EBRD Administrative Tribunal Decisions

Decisions of the Administrative Tribunal of the European Bank for Reconstruction
and Development (EBRD). The tribunal adjudicates employment disputes between EBRD
staff members and the bank.

- **Coverage:** ~61 decisions (2003–2025)
- **Language:** English
- **Format:** PDF (text extracted via pdfplumber)
- **Update frequency:** A few decisions per year

## Data source

Decisions are published at:
https://www.ebrd.com/home/who-we-are/our-organisation/ebrd-governance-leadership/corporate-governance/administrative-tribunal.html

Each decision is a downloadable PDF. The scraper parses the listing page for
download links, fetches each PDF, and extracts text using pdfplumber.
