# INTL/UNESCO-Conventions — UNESCO Legal Instruments

Conventions, recommendations, and declarations adopted by UNESCO.

- **Coverage:** 94 instruments (1948–2021)
- **Languages:** English, French, Spanish (trilingual full text)
- **Data type:** legislation
- **Access method:** UNESCO DataHub REST API (data.unesco.org)
