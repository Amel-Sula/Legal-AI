# INTL/OHCHR-TBInternet — UN Treaty Body Documentation

Country-specific observations and recommendations from the 10 UN Treaty Bodies
(CCPR, CESCR, CERD, CEDAW, CAT, CRC, CMW, CRPD, CED, SPT), Special Procedures
mandate holders, and the Universal Periodic Review (UPR).

Data sourced from the **Universal Human Rights Index (UHRI)** full JSON export
at `dataex.ohchr.org`, updated daily.

## Data

- **Type:** doctrine
- **Volume:** ~200,000+ annotations
- **Coverage:** All UN member states
- **Fields:** text, symbol, treaty body, countries, themes, SDGs, affected persons
