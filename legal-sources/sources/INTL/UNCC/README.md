# INTL/UNCC

UN Compensation Commission (UNCC) Governing Council Decisions.

- **Coverage:** Decision 1 (1991) to Decision 277 (2022)
- **Records:** ~279 decisions
- **Full text:** Extracted from official PDFs using PyMuPDF
- **Status:** Static archive — UNCC mandate concluded February 2022

## Data Source

The UNCC decisions listing page contains direct PDF links to all 279 Governing
Council decisions. The Commission was established by Security Council Resolution
687 (1991) to process claims for losses from Iraq's invasion of Kuwait.
