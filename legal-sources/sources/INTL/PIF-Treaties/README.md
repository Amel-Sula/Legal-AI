# INTL/PIF-Treaties — Pacific Islands Forum Treaty Collection

Regional treaties deposited with the Secretary General of the Pacific Islands Forum Secretariat. Covers the Noumea Convention, Waigani Convention, PACER, PICTA, SPARTECA, Rarotonga Treaty, and others.

## Data

- **Type**: legislation (international treaties)
- **Format**: PDF documents hosted on forumsec.org
- **Coverage**: ~13 regional treaties
- **Language**: English (one French version included)
