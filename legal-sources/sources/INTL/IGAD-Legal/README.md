# INTL/IGAD-Legal

IGAD (Intergovernmental Authority on Development) communiqués, summit decisions, and ministerial declarations.

**Member states:** Djibouti, Eritrea, Ethiopia, Kenya, Somalia, South Sudan, Sudan, Uganda

**Data source:** WordPress REST API at `igad.int/wp-json/wp/v2/posts?categories=52`

**Coverage:** ~115 communiqués from summits and ministerial conferences (2009–present)

**Document types:** Summit communiqués, ministerial declarations, joint statements, policy decisions
