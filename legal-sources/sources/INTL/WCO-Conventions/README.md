# INTL/WCO-Conventions

World Customs Organization (WCO) conventions and agreements — international
customs treaties governing harmonized commodity classification, temporary
admission, customs procedures, mutual administrative assistance, and more.

## Data

- ~20 conventions and agreements
- Full text PDFs from wcoomd.org
- English language primary texts
- Dates range from 1950 to present
