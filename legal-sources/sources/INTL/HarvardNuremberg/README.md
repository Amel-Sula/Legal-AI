# INTL/HarvardNuremberg — Harvard Nuremberg Trials Project

Full-text transcripts from all 13 Nuremberg trials (1945–1949), digitized by
Harvard Law School Library. Over 150,000 pages of verbatim courtroom records
covering witness testimony, oral arguments, court rulings, and judgments.

## Data access

Uses the transcript partial-rendering endpoint at
`/transcripts/{id}?seq={seq}&partial=1` which returns JSON with HTML content
for 10 pages at a time. Pages are grouped by date to create per-session records.
