# INTL/CEMACCourt — CEMAC Court of Justice Decisions

Decisions from the **Cour de justice de la Communauté économique et monétaire de l'Afrique centrale (CEMAC)** via [juricaf.org](https://juricaf.org).

- ~121 decisions
- Member states: Cameroon, Central African Republic, Chad, Republic of the Congo, Equatorial Guinea, Gabon
- Language: French
- Full text extracted from individual decision pages

## Data Access

- JSON search API: `https://juricaf.org/recherche/+/facet_pays:CEMAC?format=json`
- Individual decisions: `https://juricaf.org/arret/{decision_id}`
- Full text from `div#textArret` + Dublin Core metadata from HTML meta tags
