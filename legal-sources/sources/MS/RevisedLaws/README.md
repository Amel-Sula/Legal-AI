# MS/RevisedLaws — Montserrat Revised Laws

Fetches the full set of Montserrat legislation from the Attorney General's Chambers website (gov.ms).

## Coverage

- **Revised Laws (2019 & 2025):** Consolidated Acts in force
- **Acts Passed (2016–2026):** New legislation by year
- **SROs (2013–2026):** Statutory Rules and Orders (subsidiary legislation)
- **Omitted Laws:** Laws excluded from the main revision

~1449 PDF documents with full text extraction via pdfplumber.
