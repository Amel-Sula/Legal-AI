# PS/SecurityLegislation — Palestine Security Sector Legal Database

DCAF-operated database of Palestinian security sector legislation at
[security-legislation.ps](https://security-legislation.ps).

Contains ~2200 legal texts: laws, decrees, law by decree, decisions,
bylaws, and state of emergency legislation. English translations.

## Data Access

WordPress REST API at `/wp-json/wp/v2/latest-laws` with pagination.
Taxonomy endpoints for text type, status, and institution categories.
