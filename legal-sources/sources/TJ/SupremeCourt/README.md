# TJ/SupremeCourt — Supreme Court of Tajikistan Bulletins

Quarterly publications of the Supreme Court of the Republic of Tajikistan
(Суди Олии Ҷумҳурии Тоҷикистон):

- **Нашрияи Суди Олии Ҷумҳурии Тоҷикистон** (Supreme Court Bulletin, 2020–2024)
- **Мизони Қонун** (Scale of Law, 2025–)

Each issue compiles cassation decisions, Plenum interpretations of legislation,
doctrinal commentary on code amendments, and procedural guidance for lower courts.
Full Tajik-language text extracted from official PDFs via pdfplumber.

**Source URL:** https://sud.tj/nashriyai-sudi-oli/
