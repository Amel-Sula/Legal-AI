# Tajikistan Constitutional Court Decisions

**Source:** [https://constcourt.tj](https://constcourt.tj)
**Country:** TJ
**Data types:** case_law, legislation
**Status:** Complete

Decisions, determinations, and legal documents from the Constitutional Court
of the Republic of Tajikistan. Uses the WordPress REST API to fetch full text.

## Data Coverage

- **Decisions (qarorho):** ~29 constitutional court rulings
- **Determinations (tainotho):** ~63 constitutional determinations
- **Documents (hujatho):** ~15 legal/constitutional documents
- **Languages:** Tajik, Russian
- **Full text:** Yes, via WP REST API `content.rendered`
