# ME/AZZK — Montenegro Agency for Protection of Competition

Competition enforcement decisions from Montenegro's Agency for Protection of Competition
(Agencija za zaštitu konkurencije).

## Coverage

- **Merger decisions** (2006–2022): ~380 decisions approving, suspending, or rejecting concentrations
- **Restrictive agreements** (2011–2021): ~15 cartel/collusion decisions
- **Abuse of dominant position** (2011–2019): ~15 enforcement decisions
- **Individual exemptions** (2013–2022): ~32 exemption decisions
- **Opinions** (2010–2015): ~10 advisory opinions

Total: ~460 decisions published as PDF files.

## Data Access

HTML pages at azzk.me list PDF links per category/year. PDFs contain extractable text
in Montenegrin/Serbian. No API — scraper parses HTML for PDF links, then extracts text
via PyMuPDF.
