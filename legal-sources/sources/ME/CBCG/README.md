# ME/CBCG — Montenegro Central Bank Regulations

Central Bank of Montenegro (Centralna banka Crne Gore) regulations and laws.

## Coverage

- ~150 regulations across 10+ categories (banking supervision, payment systems, financial stability, etc.)
- ~29 laws (banking, AML, consumer protection, capital markets, etc.)
- English translations (unofficial consolidated versions)

## Data Access

HTML pages listing PDF links. No API available.
- Regulations: https://www.cbcg.me/en/about-us/legislation/regulations
- Laws: https://www.cbcg.me/en/about-us/legislation/laws

PDFs are downloaded and text is extracted using the common PDF extraction module.
