# BS/URCA-Decisions

Bahamas Utilities Regulation and Competition Authority (URCA) — regulatory decisions, adjudications, final determinations, and statements of results.

## Coverage

- **Sectors:** Electronic Communications (ECS), Electricity (ES), Natural Gas (NGS)
- **Document types:** Adjudications, final determinations, statements of results, regulatory orders
- **Period:** 2009–present
- **Volume:** 151+ decisions

## Data access

WordPress REST API with custom post type `decisions`:
```
GET https://urcabahamas.bs/wp-json/wp/v2/decisions?per_page=100&page=1
```

Most decisions have full HTML content. Some also include downloadable PDF attachments with the complete decision document.
