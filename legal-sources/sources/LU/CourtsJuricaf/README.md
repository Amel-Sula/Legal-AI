# LU/CourtsJuricaf — Luxembourg All Courts Decisions (Juricaf)

Luxembourg court decisions from [Juricaf](https://juricaf.org/), the AHJUCAF francophone court decisions database.

## Coverage

- ~27,590 decisions across all Luxembourg courts
- Full text in French
- Courts include: Cour de cassation, Cour d'appel, Cour administrative, Tribunal d'arrondissement, etc.
