# MG/CourtsJuricaf — Madagascar All Courts Decisions (Juricaf)

Madagascar court decisions from the AHJUCAF francophone court decisions database
via juricaf.org. Covers all Madagascar courts available on Juricaf:

- Cour suprême (3,060 decisions)
- Haute cour constitutionnelle (147 decisions)
- Cour de cassation (15 decisions)

## Data

- **Type:** case_law
- **Language:** French
- **Source:** Juricaf / AHJUCAF (Association des Hautes Juridictions de Cassation des pays ayant en partage l'usage du français)
- **Access:** JSON API (paginated search) + HTML detail pages with full text
- **Note:** Supersedes MG/CourSupremeJuricaf (500+ Cour suprême only). DB dedup via ON CONFLICT DO NOTHING.
