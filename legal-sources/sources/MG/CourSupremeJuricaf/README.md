# MG/CourSupremeJuricaf — Madagascar Supreme Court Decisions (Juricaf)

Madagascar Supreme Court (Cour suprême) decisions via [Juricaf](https://juricaf.org),
the francophone court decisions database operated by AHJUCAF.

Covers Supreme Court decisions across all chambers (Chambre pénale, Chambre civile,
Chambre administrative, etc.) with full text in French.

## Data

- **Type:** case_law
- **Format:** JSON (search API) + HTML (full text from decision pages)
- **Language:** French
- **Coverage:** ~500+ decisions
