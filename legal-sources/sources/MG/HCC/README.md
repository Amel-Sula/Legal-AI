# MG/HCC — Madagascar Haute Cour Constitutionnelle

Constitutional court decisions from Madagascar's High Constitutional Court (Haute Cour Constitutionnelle).

## Coverage

- **Decisions**: ~1,331 across all categories
- **Types**: Arrêts (rulings), Avis (advisory opinions), D1 (international conventions), D2 (unconstitutionality exceptions), D3 (national legislation), Elections, Délibérations
- **Period**: 2003–2026
- **Language**: French

## Data Access

WordPress REST API at `https://www.hcc.gov.mg/?rest_route=/wp/v2/posts` with category filtering. Full text HTML content returned in each post, stripped to plain text.
