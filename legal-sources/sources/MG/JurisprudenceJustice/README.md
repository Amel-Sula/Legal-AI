# MG/JurisprudenceJustice — Madagascar Court of Cassation

Court of Cassation decisions from the Madagascar Ministry of Justice jurisprudence portal.

- **Source:** [jurisprudence.justice.gov.mg](https://jurisprudence.justice.gov.mg/)
- **Data type:** case_law
- **Language:** French
- **Coverage:** 1,003 decisions (853 civil, 46 commercial, 104 social), 2009–2019
- **Method:** HTML scraping — paginated listing + detail pages
