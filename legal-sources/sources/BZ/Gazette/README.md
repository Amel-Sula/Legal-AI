# BZ/Gazette — Belize Government Gazette (Statutory Instruments)

Statutory Instruments (subsidiary legislation, regulations, orders) published in
the Belize Government Gazette. Mirrored on the National Assembly of Belize
website at `nationalassembly.gov.bz/statutory-instruments/`.

The www.gazette.gov.bz domain does not currently resolve (DNS NXDOMAIN). The
National Assembly archive is the authoritative public-facing source for SI text.

Covers 2017–present, ~150 SIs/year. Complements `BZ/NationalAssembly` (Acts of
Parliament) and `BZ/AGMLaws` (consolidated laws).

## Usage

```bash
python sources/BZ/Gazette/bootstrap.py bootstrap --sample
python sources/BZ/Gazette/bootstrap.py bootstrap --full
```
