# BZ/FSC-Legislation

Belize Financial Services Commission — Laws & Amendments.

Financial services legislation, statutory instruments, and amendments published by the
Belize FSC via their WordPress site at belizefsc.org.bz.

## Data access

- **WP REST API v2** for post enumeration (`/wp-json/wp/v2/posts?categories=...`)
- PDFs hosted at `wp-content/uploads/` — downloaded and text extracted via pdfplumber
- Legislation-related WP categories used to filter: Acts (62), Securities Industry (170),
  Companies (153, 156), FSC (169), Money Laundering (70), and others
