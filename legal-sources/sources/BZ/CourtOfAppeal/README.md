# BZ/CourtOfAppeal — Belize Court of Appeal Judgments

Court of Appeal judgments from the Judiciary of Belize, covering Criminal
Appeals (1977–2022) and Civil Appeals (1987–2022).

## Source

- **URL**: https://judiciary.bz/judgements3/
- **Format**: PDF documents hosted on WordPress
- **Coverage**: ~400+ judgments across Criminal and Civil divisions
- **Update frequency**: Periodic (new judgments added as decided)

## Method

1. Parse the main index page to discover year-page URLs
2. For each year page, extract all PDF links
3. Download PDFs and extract full text using pdfplumber
